## 작성 기준

- 프로젝트 개발 가제는 `wayMate`로 통일합니다. 최종 서비스명은 별도로 결정합니다.
- 기능 ID `DM01`~`DM11`은 후속 문서에서도 동일하게 사용합니다.
- 서비스 목표, 목업의 실제 동작, 대본·시연 데이터에 의한 재현을 구분합니다.
- 후속 문서에서 제작 범위를 바꾸면 01번 문서와 관련 검수 항목도 함께 갱신합니다.
- 작성 예정 문서는 실제 파일이 생긴 뒤 링크를 추가합니다.
