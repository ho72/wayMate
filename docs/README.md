## 작성 기준

- 프로젝트 개발 가제는 `wayMate`로 통일합니다. 최종 서비스명은 별도로 결정합니다.
- 기능 ID `DM01`~`DM11`은 후속 문서에서도 동일하게 사용합니다.
- 서비스 목표, 목업의 실제 동작, 대본·시연 데이터에 의한 재현을 구분합니다.
- 후속 문서에서 제작 범위를 바꾸면 01번 문서와 관련 검수 항목도 함께 갱신합니다.
- 작성 예정 문서는 실제 파일이 생긴 뒤 링크를 추가합니다.

## v0.4 설명·용어 보완

2026년 11월 11일 01~05번을 다시 읽고, 기능 이름만으로 동작이나 시간의 뜻을 추측해야 했던 부분을 보완했습니다. 아래는 문서 반영 내용이며 구현·사용자 이해도·실제 SDK 검수 완료 기록은 아닙니다. 담당자와 마감은 미정으로 유지합니다.

| 항목 | 보완한 기준 | 반영 문서 |
|---|---|---|
| 내비 요청의 대상 | 기존 목적지는 유지하고 만남 카페를 중간 경유지로 추가하는 요청의 전·중·후. 약속 취소와 만남 완료, 경유지 제거를 구분 | 01~05 |
| 콘텐츠의 목적과 예시 | 서로 알아가고 스몰토크를 돕는 선택형 콘텐츠로 설명. 현재 목록은 목업용 대표 방식이며 밸런스 게임은 제작 채택 미정인 확장 아이디어 | 01~05 |
| 시간·복귀 장소 | 가능 시간 전체가 만남 길이는 아님. 실제 첫 만남 20분·기존 다음 일정·숙소 도착 예상/마감 구분. 불명확했던 복귀 장소는 대표 시연의 각자 강릉권 숙소로 명시 | 01~05 |
| 화면·데이터 표현 | ‘만남 카페를 경유지로 추가’, ‘기존 다음 일정 도착’, ‘내 숙소 도착 예상/마감’으로 구체화. 본인 복귀 장소 라벨·정보의 공개 경계 반영 | 02~05 |

## v0.3 통합 검토 반영

| 조건별 대사 | 고정 대사의 비공개 취향·차분한 표현·선행 대화 가정 문제 수정. 중립/일정 중심/일반 인사와 cue 선행·대체 대사 명시 | 01~05 |

| 최종 재시연 | 만남 종료 후 checkpoint로 통일. 서버의 final_replay 제한, 현재 내비·제한·복구 기록 보존, 새 사회적 요청 차단 | 01~05 |
