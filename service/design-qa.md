# 모바일 실제 서비스 화면 QA

final result: passed

## 비교 범위와 증거

출발점은 사용자 제공 `말이통행_v5_Interactive.html`과 이를 적용한 기존 모바일 화면이다. 현재 요청은 **실제 계정/자유 대화/개인 여행 저장 기능 확장**이므로 기존 목업의 고정 상담 질문·시연 표시·단계 이동은 의도적으로 교체한다. 새 홈·계정·보관함은 시안에 없는 서비스 화면이다. 이 QA는 시안의 시연 내용을 그대로 복제했다는 판정이 아니라, 같은 디자인 계통 안에서 실제 기능을 사용할 수 있는지의 판정이다.

- 시각 기준: 기존 검수된 `mock-app/runtime/design-v5-reference/mobile-chat.png` 430×932 및 [v5 모바일 증거](../docs_prototype/evidence/v5-mobile-2026-11-14.png), [28번 디자인 기준](../docs_prototype/28_v5_디자인_적용_및_검수.md).
- 구현: [430×932 실제 상담·저장](../docs_prototype/evidence/service-mobile-chat-2026-11-14.png), [홈](../docs_prototype/evidence/service-mobile-home-2026-11-14.png), [로그아웃 홈](../docs_prototype/evidence/service-guest-home-2026-11-14.png), [프로필](../docs_prototype/evidence/service-mobile-profile-2026-11-14.png), [1360×1000 데스크톱](../docs_prototype/evidence/service-desktop-home-2026-11-14.png).
- 같은 430×932 영역으로 배치한 [전체 비교 884×972](../docs_prototype/evidence/service-design-comparison-2026-11-14.png)를 열어 검토했다. 왼쪽은 시연형 상담 시작, 오른쪽은 실제 AI 상담 완료/저장 상태이므로 내용과 진행 상태의 픽셀 일치를 주장하지 않는다. 읽을 수 있는 동일 크기의 입력 영역·본문·아이콘·카드를 직접 확인했으며 추가 확대 합성은 필요하지 않았다.
- 브라우저 배율은 1.1로 관측됐다. 실제 CSS 430×932를 확인한 뒤 캡처 clip 473×1025로 원래 화면 전체를 430×932 PNG에 담았다. 기존 fullPage 캡처가 배율을 중복 차감해 오른쪽/아래를 자르던 문제는 초기 증거에서 제외했다. 레이아웃 자체의 넘침은 DOM 경계와 별도로 판정했다.
- 320×820 및 기본 319px에서도 root/main scrollWidth가 clientWidth와 같았다. 데스크톱 1360×1000에서도 root 1360, main 1104로 넘침이 없었다. 임시 viewport는 검수 뒤 복원했다.

## 필수 표면 판정

- **글꼴/타이포:** 기존 Inter/Pretendard/Apple SD Gothic Neo 계통을 유지한다. 본문 14–15px, 채팅 15px/1.85, 모바일 주요 제목 25–28px. 모바일 헤더는 긴 실제 문장을 한 줄로 줄이고 행동 버튼을 보존한다. 짧은 카드 보조 글은 원 시안 계통의 작은 크기를 유지한다.
- **간격/구조:** 모바일 19px 안쪽 여백, 17–24px 카드 곡률, 44–48px 주요 터치 행동. 새 홈은 큰 캐릭터·대화 시작·저장 여행 순서다. 데스크톱은 기록 사이드바를 제공하고 모바일은 하단 4개 메뉴를 사용한다. 긴 대화와 프로필은 본문만 스크롤하며 입력/메뉴를 유지한다.
- **색/토큰:** 기존 ink #203449, blue #226eeb, 옅은 하늘색/민트·흰 카드·절제된 테두리를 유지한다. 저장 상태는 초록 체크와 글로 함께 표현한다. 상태를 색에만 맡기지 않는다.
- **이미지:** 기존 생성 투명 용/곰 PNG를 공유하고 object-fit:contain으로 비율을 보존한다. 홈 전신·프로필 선택·작은 발화자 이미지에서 왜곡/배경 테두리 없음. PNG 표시이며 실제 3D 리깅으로 설명하지 않는다. 아이콘은 제공된 디자인의 원본 SVG 심볼이다.
- **문구/내용:** 실제 저장 데이터와 빈 상태를 사용한다. 초안/저장 완료를 분리하고 AI 전달 동의를 명시한다. 날짜·장소를 실제 조회/예약한 것처럼 보이는 성공 문구는 넣지 않는다. 시연 전용 운영자 버튼·준비된 상대·목업 통계는 없다.
- **상태/접근성:** 계정 모달, disabled·focus-visible, 입력·전송, 로딩·실패·취소·보관·저장·빈 상태 확인. 프로필 폼 label과 캐릭터 radio, dialog 제목, 상태 알림을 제공한다. 선택한 캐릭터로 대화 폼의 접근성 이름도 갱신한다. reduced-motion 설정을 따른다.

## 기능 검수와 잔여 범위

가입 → 동의 → 실제 취향 후보 → 직접 기억 → 일정 제안 → 직접 저장 → 상세 → 새 대화에서 저장 정보 조회 → 캐릭터 수정 → 보관/복원 → 재시작/재로그인 → 동의 철회 → 로그아웃을 브라우저에서 조작했다. 최종 console error/warn 없음. 서비스 자동 회귀 15, 기존 회귀 314 통과.

검수용 계정에서 로그아웃한 홈을 열어두었다. 시안에 없던 실제 서비스 화면의 픽셀 일치, 실차 화면, 음성 상담, 실제 사용자 매칭·차량 페어링, 공개 배포 품질은 이 통과 판정에 포함하지 않는다. 이 범위는 [29번](../docs_prototype/29_모바일_실제_에이전트_서비스.md)의 후속 계약을 따른다.
