# README 화면 캡처

[메인 README](../README.md)에 사용하는 대표 UI 8장입니다.

- `screenshots/mobile-*`: 실제 모바일 웹의 촬영·검수 화면. 채팅은 촬영용 고정 응답, 여행자 추천은 고정 후보를 사용합니다.
- `screenshots/vehicle-*`: 실제 Pleos 에뮬레이터의 네이티브 앱 화면. 오프라인 Debug 미리보기입니다.
- `screenshots/ending-*`: 함께 / 각자 결말을 각각 표시한 미리보기입니다.

캡처는 서로 다른 검수 회차의 예시입니다. 화면 속 날짜·별명·여행이 다를 수 있으며, 이미지로 실제 상대 통신·실시간 지도·기기 전체 완주를 증명하지 않습니다. 앱 실행용 캐릭터·음성은 `backend/demo/assets/`에서 관리합니다.
