# 두루밋 차량용 확인 패널

2026-11-15 · 차량 앱의 팝업 구성과 안드로이드 기본 디자인에 대한 사용자 피드백을 반영했다. 38번에서 키운 버튼의 조작성은 유지하고, 기본 Material AlertDialog 틀을 VehicleConfirmationDialog로 교체한다. PR은 생성하지 않는다.

## 판단과 구성

경유지 변경·연결 해제·선택 제출 등 명시 확인이 필요한 작업에는 팝업을 유지한다. 단순 정보/진행 상태는 본문 상태 표시를 우선한다. 이번 변경은 새로운 팝업을 추가하지 않는다.

- 최대 폭 840dp, 24dp 모서리, 두루밋 Canvas·Forest·SkyLine 색상 사용.
- 제목 32sp, 일반 본문 24sp. 본문이 길면 정보 영역만 스크롤하고 하단 행동을 유지한다.
- 하단의 취소/실행은 같은 폭이며 최소 높이 112dp, 글자 26sp. 확인은 채움, 취소/복귀는 테두리.
- 바깥 영역 탭으로 닫지 않는다. 기기 뒤로 가기는 기존 onDismissRequest를 사용하며 실제 취소/승인 명령을 대신 실행하지 않는다.
- 경유지 추가/제거는 선택 장소와 유지되는 목적지를 별도 정보로 표시한다. 버튼은 `경유지 추가`/`경유지 제거`처럼 실행할 동작을 표시한다.

## 적용과 경계

여행 시작·연결 종료·공개 철회, 말 전달·만남·최종 선택, 내비 승인·초기화, 계정 연결·수신·해제의 확인창이 같은 패널 틀을 사용한다. 기존 콜백·활성 조건·중복 방지·내비 실행권·journal·주행 제한은 바꾸지 않는다. 경유지 요약은 기존 실제/모의 구분과 선택한 목적지를 유지한다.

모의/실제 Debug 빌드와 데이터 보존 설치를 마쳤다. 시각 점검의 수정 전/후/인포테인먼트 문맥 캡처는 [별도 기록](evidence/dialog-v3-2026-11-15/README.md)에 있다. 전체 기능·실차·플랫폼 심사 통과를 의미하지 않는다. 남은 검증은 36번에 기록한다.

## 참고한 공식 가이드

- [Google Automotive OS Dialogs](https://developers.google.com/cars/design/automotive-os/components/dialogs): 확인/선택 모달의 목적, 방해 요소이므로 절제해서 사용, 제목/본문/행동 영역 구성. OEM Car UI Library 구성과 이번 앱 내부 Compose 패널을 동일한 구현으로 주장하지 않는다.
- [Pleos 주의 분산 최소화](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-planning-guide/driver-distraction-guideline): 큰 터치 영역·높은 대비·최소 문구, CarUxRestrictions에 따른 제한. 이번 치수는 UI 설계값이며 공식 요구 치수 충족 검증이 아니다.
