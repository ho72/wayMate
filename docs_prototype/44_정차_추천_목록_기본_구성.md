# 정차 추천 목록 기본 구성

2026-11-15. 휴식 목록(WF-035)과 점심 목록(WF-044)에 확정한 CompanionScene 기본 구성을 적용했다.

- 2분할: 좌측 캐릭터·우측 제목과 추천 카드. 3분할: 캐릭터 아래 가운데 제목과 추천 카드.
- 캐릭터 크기/이동, 위 여백, 말풍선과 간격은 기존 공통 컴포넌트를 사용한다. 2분할 460dp·위로 16dp, 3분할 260dp 영역에서 1.15배·위로 36dp다.
- 세 후보를 하나의 반투명 카드에 번호·이름·가상 표시·소요 시간으로 정리했다. 추천 이유·주소 등 자세한 내용은 기존 상세에서 확인한다.
- 각 행 전체가 최소 높이 96dp의 선택 영역이다. 우측 ‘자세히 ›’와 접근성 버튼 역할/장소별 동작 설명을 제공한다. 탭하면 기존 flow.select(place.id)로 해당 상세에 진입한다.
- 공통 이전은 질문 화면으로 돌아간다. 목록 아래의 중복 질문/홈 복귀 및 기술적 미리보기 설명·화면 목록 링크는 기본 화면에서 제외했다. 다른 상세/결과 화면은 이번 변경 대상이 아니다.
- 정차 활성 조건과 미확인 요청 잠금에서 선택 비활성 조건을 유지한다. 주행 전용 추천 요약/자동 음성 안내는 별도 화면을 사용한다.

mockDebug 빌드·설치, 실제 1682×1210/841×1210 창에서 휴식·점심 세 후보의 초기 표시를 확인했다. 정차 Debug 호스트에서 세 번째 휴식 후보(해변카페) 탭 → 해당 상세 → 이전으로 목록 복귀를 확인했다. 서버·실제 추천/내비를 검증한 결과는 아니다.
