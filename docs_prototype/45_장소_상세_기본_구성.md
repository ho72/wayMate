# 장소 상세 기본 구성

2026-11-15. 휴식 상세(WF-036)와 식사 상세(WF-045)에 확정한 CompanionScene 템플릿을 적용했다.

- 2분할은 좌측 캐릭터·우측 제목/정보 카드/두 행동, 3분할은 캐릭터 아래 가운데 제목/정보 카드/두 행동이다. 캐릭터와 헤더/이전은 공통 규격을 사용한다.
- 제목은 선택 장소명·가상 표시다. 카드에는 추천 이유·소요 시간·주소와 다음 일정/방문지·숙소 복귀 예상/마감 시각을 정리했다. 일정 관련 정보를 카드 아래에 중복 표시하지 않는다.
- 시연 좌표와 기술적인 미리보기 설명은 기본 상세 UI에서 제외했다. 데이터·다음 경로 확인 화면과 기존 모의 동작은 보존했다. 실제 목적지/POI 검증이나 SDK 연결을 추가하지 않았다.
- ‘이곳으로 안내 확인’과 ‘다른 장소 보기’ 또는 ‘다른 식사 장소 보기’를 청록/민트 주요 버튼으로 나란히 배치했다. 첫 버튼은 기존 reviewRoute()를 통해 별도 경유/목적지 확인 화면으로 이동한다. 바로 경로를 변경하지 않는다. 미확인 요청 잠금 상태에서는 기존 결과 확인으로 연결하며 문구를 ‘안내 결과 확인’으로 구분한다.
- 이전과 다른 장소 보기는 기존 목록으로 돌아간다. 중복 ‘내 친구 홈으로’는 제거했다. 활성 확인 전에는 두 행동을 비활성화하고 안내를 표시한다.

mockDebug 빌드·설치, 휴식 상세의 실제 1682×1210/841×1210 창과 식사 상세 841×1210 창의 초기 표시를 확인했다. 정차 Debug에서 휴식 상세 → 경유 확인 → 이전 → 상세 → 다른 장소 보기 → 목록을 확인했다. 경유 추가 승인·실제 내비 실행은 하지 않았다.
