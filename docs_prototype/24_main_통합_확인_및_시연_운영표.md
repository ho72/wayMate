# main 통합 확인과 시연 운영표

2026-11-13. [23번 개발·검수 기록](23_1차_개발_완료_및_검수.md)에 이어 W17의 시연 준비를 정리한다. 01~05번의 범위·대사·동의 순서를 따른다. 이 문서는 발표자 시간 리허설의 완료 기록이 아니다.

## 머지된 기준

- PR [#6](https://github.com/ho72/wayMate/pull/6), [#7](https://github.com/ho72/wayMate/pull/7)은 main에 머지됐다. 기준 커밋은 `9b18f711860d583243bf283d30b6525e52f4c2af`다.
- 이 main의 파일 트리는 리뷰 후 검증한 `5c29dbe`와 동일하다. Node 264·JVM 41·기기 7개 결과는 23번의 후속 회귀를 참조한다. 같은 테스트를 다시 실행한 것처럼 합산하지 않는다.
- main 자동 검사도 [서버·계약](https://github.com/ho72/wayMate/actions/runs/43376453115)·[차량 빌드·JVM·Lint](https://github.com/ho72/wayMate/actions/runs/43376453100) 모두 통과했다.
- 머지 후 서버 `/health`, 모바일 `/`, O01 `/operator`와 역할을 지정한 scenario 응답을 확인했다. 역할 없는 API 요청은 403으로 차단됐다. 실행 상태와 SDK journal을 초기화하거나 새 성공 기록을 만들지 않았다.
- APK 두 종류·서버·웹·계약·소재·문서를 main 기준으로 다시 묶었다. 실제/모의 APK는 기본 포트 3000이며 개인 상태·SDK journal은 묶음에서 제외한다.
- 순정 내비 도로 배경 표시는 보류 중이다. 3분할은 계기판 / 순정 내비 / wayMate 순서다. 지도 배경과 경유지 실제 반영 결과는 별도로 설명한다.

## 다른 결말 · 추가 목표 60초

1. O01의 `최종 선택 재시연`을 누른다. 전체 초기화나 새 내비 추가를 하지 않는다.
2. 같은 새 final round에서 B가 먼저 `B 내 캐릭터와 여행 이어가기`를 고른다. A 화면에서 B의 선택이 공개되지 않는 것을 확인한다.
3. A도 본인 선택을 제출한다. 양쪽 제출 후 각자 결말이 확정되는 것을 확인한다.
4. A의 친구 대화·현재 문장 직접 낭독·다음 활동·본인 일정을 보여준다. 선택 이유 입력 없이 종료한다.
5. 이 재시연은 새 매칭·메시지·통화·내비 호출을 만들지 않는다. 실제 경유지 정리는 아래 종료 절차로 따로 진행한다.

## 종료와 측정 기록
