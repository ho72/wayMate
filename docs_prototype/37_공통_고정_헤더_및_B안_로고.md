# 두루밋 공통 고정 헤더 · B안 로고

2026-11-15 · 사용자가 선택한 최초 B안 로고를 적용한다. PR은 생성하지 않고 로컬 UI로 먼저 확인한다.

## 공통 구조

- 왼쪽: 원본 B안의 점 두 개·곡선 길·둥근 두루밋 글자를 포함하는 동일 로고. 모든 화면에서 198×45dp, 왼쪽 28dp 위치를 유지한다. 로고를 뒤로 가기 버튼으로 바꾸지 않는다.
- 가운데: `정차 중`, `주행 중 · 간편 모드`, 상태 미확인 때 `상태 확인 중`. 실제 모드는 기존 차량 제한 관측을 따른다.
- 오른쪽: 기존 흰색 반투명 둥근 태그를 유지한다. `나만의 여행`, `장소 찾기`, `점심 추천`, `경로 확인` 등 사용자가 읽는 현재 페이지명을 표시한다. WF 번호는 개발용 목록과 테스트 식별자에만 유지한다.
- 헤더는 높이 112dp의 동일한 틀이며 본문 스크롤 바깥에 위치한다. 본문이 헤더 위로 그려지지 않게 영역을 분리한다.
- 하위 화면의 `‹ 이전`은 로고 아래 별도 고정 행이다. 기존 뒤로 가기/화면 종료 동작을 사용하며 요청·약속 취소 명령으로 바꾸지 않는다. 개인 안내 요청 중에는 이전 버튼을 새로 노출하지 않는다.

## 적용 범위

여행 준비/홈, 캐릭터 대화/상대 소개/말 전달/답장/통화, 만남, 내비, 재연/선택/결말, 초기화/복구, 계정 연결/개인 여행, 추가 차량 페이지 16개, Debug 미리보기 목록, 주행/제한 화면에 같은 헤더를 사용한다. 대화와 결말 캐릭터 영역의 중복 서비스명과 스크롤 본문 안의 옛 헤더는 제거했다.

계정 여행은 기존 실제 제한 관측을 표시용 모드로 함께 전달한다. 계정·수신·내비 승인 조건이나 주행 조작 권한은 변경하지 않는다. 주행 음성 문답·새 대화 기능을 연결하는 변경은 아니다.

## 로고 소재

선택 원본은 `durumit-logo-b.png`이며 앱의 `res/drawable-nodpi/durumit_logo_b.png`에 그대로 복사한다. 원본 글자나 길 심볼을 새로 그리거나 다른 서체로 바꾸지 않는다. 표시할 때 로고 영역을 잘라 사용하고 흰 배경은 Multiply 합성으로 헤더 배경과 섞는다. 원본은 보존한다.

## UI 확인과 남은 검증

모의·실제 Debug APK를 빌드해 UI를 표시한다. 캡처는 Debug 미리보기에서 실제 화면 컴포넌트를 가상 여행 상태로 렌더링하며, 실제 차량 주행 상태를 바꾸지 않는다. 이전 캡처는 `evidence/header-review-2026-11-15/`, 변경 후 캡처는 `evidence/header-v2-2026-11-15/`에 분리한다.

전체 기기·접근성·기능 회귀를 완료한 것으로 표시하지 않는다. 841/1682dp 창 크기, 130% 글자, 긴 태그, 모든 페이지의 스크롤 고정, 뒤로 가기·제한 복귀는 [36번](36_차량_UI_검증_필요_항목.md)의 후속 검증이다.

## 헤더 가독성 조정

차량에서 작은 글자와 누르기 어려운 조작을 피하고 싶다는 사용자 피드백에 따라 모드 주 표시는 18sp에서 26sp/Bold로, 페이지 태그는 16sp에서 24sp/Semibold로 키웠다. 주행 표시는 `주행 중` 26sp와 `간편 모드` 22sp의 두 줄로 분리했다. 태그는 최소 높이 64dp, 헤더는 112dp다. 태그는 상태 표시용이며 누르는 버튼으로 만들지 않는다.

`‹ 이전`은 글자 24sp, 최소 누름 영역 136×76dp로 키웠다. 기존 공통 주요/보조 버튼은 최소 높이 76dp, 홈 주요 행동은 최소 높이 88dp를 유지한다. 선택한 로고의 크기와 모드에 따른 기능 제한은 변경하지 않는다.

이 수치는 이번 UI 조정값이며 실차 거리에서의 가독성이나 플랫폼 심사를 통과했다는 뜻은 아니다. 변경 후 표시 캡처는 `evidence/header-v3-2026-11-15/`에 분리한다.
