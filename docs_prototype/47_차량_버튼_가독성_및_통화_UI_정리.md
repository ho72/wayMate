| 전체 UI 정리 | 단독 버튼/동일 위계 쌍/보조 행동 규칙, 충분한 누름 영역, 본문 대비와 정보 위계 적용 |

## 서브에이전트 디자인 리뷰

사용자가 요청한 ‘15년차 차량 UI 디자이너 관점’의 서브에이전트 리뷰를 진행했다. 실제 경력자/사람이 검수했다는 뜻이 아니며 시각·레이아웃 검토만 다룬다.

### 1차 — 반려

동일한 13개 상태의 2·3분할 26장을 검토했다.

- P1: 권장 3분할에서 주요 행동이 화면 밖으로 밀림. 본문 글자는 유지하고 하단 고정 행동/본문 스크롤·상단 장식 축소로 수정.
- P1: 계정 여행에서 받기/날짜/해제 혼재, 최종 선택 중단의 위계, 통화 제안/건너뛰기 배치 수정.
- P2: 안내 카드의 장소·목적지 유지 중복 제거.
- P2: 통화 종료의 아치/다음 자막의 글자 기호를 명확한 벡터 아이콘으로 교체.

[1차 캡처 보관](evidence/ui-polish-2026-11-15/review-round-1/). 위 4개를 반영한 뒤 같은 상태로 재검토한다.

### 2차

**대표 화면 리뷰 OK.** 동일 13개 상태×2개 창 26장을 다시 확인해 1차의 4개 요구가 해소됐다는 컨펌을 받았다.

- 3분할 주요 행동 초기 노출, 계정 행동 묶음, 제출/중단 위계, 안내 중복 문구, 통화 아이콘과 일정 카드 가독성을 확인했다.
- [2차 캡처 보관](evidence/ui-polish-2026-11-15/review-round-2/).
- 검토한 대표 상태의 시각·배치 범위다. 나머지 전체 상태는 추가 캡처 후 마지막으로 누락/잘림을 확인한다.

## 구현 범위

- 홈·기본 대화 구도는 유지한다. 정보 많은 3분할 화면은 상단 장식·캐릭터 영역을 압축해 본문 영역을 확보하고 주요 행동을 하단에 고정한다.
- 통화 화면은 기존 템플릿의 예외다. 실제 마이크·실시간 통신·가짜 통화 시간/음소거 상태를 추가하지 않았다. 준비된 음성과 자막이라는 표시를 유지한다.
- 만남/메시지/최종 선택/내비/계정의 확인 패널과 승인·상태 제한은 유지한다. 미확인 결과를 성공으로 바꾸거나 새 안내 요청을 허용하지 않는다.
- 안내 대기의 ‘결과 확인 중’과 미확인의 ‘확인 후 새 안내 승인’은 실행할 수 없는 버튼 모양이어서 상태 안내로 정리했다.
- 실제 음성·차량 제약·계정·SDK·화면 복원과 접근성 검증은 [36번](36_차량_UI_검증_필요_항목.md)에서 별도 관리한다.

### 3차 — 전체 3분할 점검, 수정 1건

기존 상태 64개와 홈/기본 대화/장소/주행 공통 화면 10개를 포함해 **74개 상태**를 점검했다. 주요 행동 노출·후보 3개 행·큰 본문·캘린더·통화/MC의 위계와 기본 UI의 시연 조작 제거를 확인했다.

- 추가 지적: 모의 초기화·복구의 ‘모의 경유지 제거 승인’과 ‘정리 상태 다시 확인’이 맞닿음.
- 수정: 고정 행동 슬롯의 여러 그룹 사이에도 **16dp 수직 간격**을 적용. 내비·복구 7개 상태를 재촬영해 최종 확인한다.
- [수정 전 캡처](evidence/ui-polish-2026-11-15/review-round-3/reset-mock-before-3split.png).

### 4차 — 전체 최종 확인

**최종 시각·배치 리뷰 OK.** 서브에이전트가 공통 화면 포함 74개 상태×2개 창 **총 148장**을 확인하고 추가 필수 수정 사항이 없다고 판정했다.

> 최종 시각·배치 리뷰: OK. 74개 상태의 2분할·3분할 총 148장 기준으로 추가 필수 수정 사항 없습니다.

- 단독 버튼 중앙 정렬, 주요/보조 행동의 우선순위, 3분할 주요 버튼 노출과 그룹 간격을 확인했다.
- 통화 전용 구성·벡터 아이콘, 캘린더 일정·복귀 마감, 확대된 본문, 시연 조작의 Debug 분리를 확인했다.
- 마지막 참고 사항인 복구 미리보기 문구도 추가/제거 혼동이 없게 수정했다.
- 한 장이 저장 도중 읽혀 불완전했던 통화 대기 PNG를 다시 만들었다. 캡처 스크립트에 읽기 재시도·PNG 청크/CRC/IEND/zlib 검증을 추가했고, 최종 [148장 무결성 기록](evidence/ui-polish-2026-11-15/captures-integrity.json)에서 모두 통과했다.
- 이 OK는 제공된 정차 Debug 캡처의 **시각·배치**에 한정한다. 실제 기능·SDK·음성 인식·접근성·기기 및 실차 검증으로 확대하지 않는다.
