# Pleos 화면과 백엔드 연동 보완

2026-11-15. 모바일 수정은 이번 작업에서 제외했다. 새 모바일 계정 흐름과의 통합은 별도로 진행한다. PR은 만들지 않았다.

## 변경

- 음성 요청에 화자 avatar ID를 함께 전달한다. 생성 대사 문구를 검색해 화자를 추측하지 않고, 준비 답변·답장·통화·만남 재연에서도 내 친구와 상대 루밋의 서버 음성 선택을 구분한다. 자동 장소 질문은 준비 음원/기기 TTS만 사용해 원격 생성·동의창을 자동으로 열지 않는다. 해당 출력은 캐릭터별 원격 음성 보장과 구분한다.
- 장소 질문은 화면 진입 때 한 번만 안내한다. 포커스 복귀만으로 재생하지 않는다. 추가 화면의 다음/뒤로/종료에서 이전 음성을 중단한다.
- 자막 VOICE/MC가 실제 출력 없이 말하기·듣기 애니메이션을 표시하던 부분을 대기·자막 확인으로 바꿨다. 실제 출력은 speech.phase에 따라 말하기/준비/중단/실패를 표시한다. Debug의 명시적 말하기·듣기 미리보기는 유지한다. 실제 STT는 추가하지 않았다.
- 시스템 뒤로가기가 현재 대화의 내부 목록 또는 이전 차량 화면으로 돌아가고 음성을 중단하도록 연결했다. 화면 복귀로 메시지·통화·경로 명령을 새로 보내지 않는다.
- 만남 이름·날짜·시작/종료 시각과 소요 시간은 서버 social.meeting을 화면과 승인창에 반영한다. 만남 정보나 조작 가능 상태가 바뀌면 이전 확인창을 폐기한다. 오프라인 UI fixture의 기본값은 별도다.
- 대사 요청은 scope와 revision을 함께 식별하고, 대기열의 오래된 요청·주행/비활성 전환·이전 여행의 늦은 응답을 폐기한다. 여행/공개 정보나 대사가 바뀌면 이전 음성을 중단한다. 생성 packet 중 준비 답변 fallback 슬롯은 AI 생성 소개로 표시하지 않는다.
- 디자인 리뷰에서 실제 3분할 결말의 두 번째 선택지가 하단 내비 버튼에 가려지는 문제를 확인했다. 내비 확인을 본문 보조 행동으로 옮기고 두 선택지가 고정 주요 버튼 위에 보이도록 수정했다.

## 백엔드 조율

백엔드 채팅은 서버/계약/캐시, 이 채팅은 차량 앱/UI/기기 검증을 담당했다. 원본3000 서버의 강릉2026-12-14 회차와 대사 캐시를 보존하고, 별도3015 서버로 검증했다. 두 서버의30개 대사 원문은 동일하다.3015는 외부 생성 provider를 끄고 저장 packet만 재사용하며 TTS available=false다.

서버는 캐시 읽기/쓰기 후 회차·문맥 재확인, 호출 직전 정차 재확인, 단일 writer lock, 중단된 생성의 문맥별 예약 영수증으로 중복 호출 방지를 보완했다. 기존3000 state/대사 해시와 OpenAI attempts=2는 그대로 유지됐다. 이번 보완 검증의 OpenAI·ElevenLabs 추가 호출은0이다.

화자·재생 상태·뒤로가기·서버 만남 시간·지연 대사 폐기 검사는 localhost fixture/기존 MP3로 실행했다. 이는 원격 ElevenLabs 새 생성 성공 검증이 아니다.

## 남아 있는 범위

- 새 모바일 계정에서 실제 사용자 여행을 준비·전달하는 통합은 이번 범위에서 제외했다. 이번 기기 시연은 서버에 준비된 가상 여행으로 시작한다.
- 실제 마이크/STT·음성 선택/정정/별도 전송 승인·실시간 상대 통화는 연결하지 않았다.
- 실차/OEM 주행 제한·실제 내비 SDK·오디오 우선순위·전체 기기 회귀는 별도 확인이 필요하다. 이번 연속 시연은 실제 정차 상태와 모의 내비로 검증했다.
- 개인 장소/개인 안내·MC 참여·기록/장식은 기존 로컬 시연 범위다. 개인 POI나 MC 동의를 실제 서버 성공으로 바꾸지 않았다.
