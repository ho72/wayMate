# 두루밋 버튼 비율·누름 영역 조정

2026-11-15 · 사용자가 이전 버튼이 작고 일반 버튼이 지나치게 가로로 길다고 지적했다. 헤더의 로고/모드/페이지 태그는 유지하고 공통 버튼 비율을 조정한다. PR은 생성하지 않는다.

| 구성 | 변경 |
|---|---|
| 이전 | 후속 사용자 수정: 배경·테두리 없는 텍스트 버튼. 폭 196dp, 최소 높이 96dp, 글자 34sp·줄 높이 44sp. 고정 헤더 아래 좌측 정렬. 이전 테두리 버튼 캡처는 변경 이력으로 보존. |
| 홈 주요/보조 | 최대 폭 440dp, 최소 높이 112dp. 청록/민트 구분과 글자 25sp 유지. |
| 일반 선택/테두리 보조 | 최대 폭 440dp, 최소 높이 104dp, 글자 24sp. |
| 확인 팝업 | 작은 TextButton 대신 공통 VehicleDialogButton. 폭 180~280dp, 최소 높이 88dp, 글자 24sp. 확인은 채움, 취소/복귀는 테두리. |

일반/홈 버튼은 기본 최소 폭 240dp를 요청하되, 좁은 부모 영역에서는 부모의 가용 폭을 따른다. 화면/Row의 가로 배치 공간과 실제 누르는 Button 영역을 Box로 분리해 부모가 넓어져도 실제 버튼은 440dp를 넘기지 않는다. 부모가 지정한 weight·스크롤·배치는 유지한다. 긴 문구는 버튼 높이가 더 커질 수 있다. 시연 조건/일정 접기 같은 텍스트 보조 조작은 이번에 디자인을 바꾸지 않았다.

확인창의 저장·전송·승인·취소 콜백과 enabled 조건은 그대로 사용한다. 상태 잠금·SDK 호출·주행 조작 권한은 바꾸지 않는다. 작은 팝업에서 확인/취소가 한 줄에 들어가지 않으면 기존 Material 대화상자의 흐름 배치에 따라 세로로 쌓인다.

현재 공통 컴포넌트를 그대로 렌더링한 비교 캡처는 `evidence/buttons-v2-2026-11-15/`에 저장한다. 기존 버튼 캡처는 `evidence/buttons-review-2026-11-15/`에 유지한다. UI 빌드·표시 확인과 실제 운전석 조작/전체 기능 검증을 구분한다. 후속 검증은 36번 문서를 따른다.
