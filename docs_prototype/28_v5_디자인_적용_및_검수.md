# v5 디자인 적용 및 검수

2026-11-14 · 사용자가 제공한 `말이통행_v5_Interactive.html` 시안 기준.

## 적용 범위

차량 홈·대화/말 전달/샘플 통화·만남·내비 승인·최종 선택/두 결말·안전한 초기화·주행 간편 모드와 모바일 대화/소개/여행/공개/추천에 같은 표시 규칙을 적용했다. 앱 표시명은 **말이통행**이며 저장소·패키지·프로토콜 이름 wayMate는 유지한다.

- 하늘색 → 옅은 민트 배경, 청록 주 버튼, 둥근 흰 말풍선·정보 카드.
- 정차 화면은 큰 캐릭터와 핵심 선택 우선. 본문 18–20sp, 제목 26–40sp, 핵심 버튼 76–88dp, 터치 영역 64dp 이상. 기존 화면의 보조 버튼도 같은 규격을 사용한다.
- 홈의 종료·공개 철회는 `여행 관리`, 자세한 일정·이동 정보와 대화의 음성 안내는 펼쳐서 본다. 두 최종 선택은 같은 크기·같은 강조로 표시한다.
- 용·곰은 내장 ImageGen으로 배경·잘린 문구를 제거한 투명 PNG를 생성했다. 웹·차량이 같은 이미지를 사용한다. [원본 파일·프롬프트](../mock-app/assets/images/design-v5/README.md), [자산 계약](../mock-app/shared/assets-manifest.json).
- 모바일은 자연스러운 자유 입력 대화와 기존 실제 AI 상담을 유지한다. 캐릭터 선택·소개 확인·여행 저장·공개 범위·추천 상세를 새 색과 카드·버튼으로 정리했다.

## 시안과 실제 기능의 연결

HTML은 디자인 참고 자료다. 그 파일의 일괄 단계 이동·B 대신 수락·목업 ETA·원클릭 초기화를 제품 동작으로 복사하지 않는다. 최종 매칭 확인은 모바일, 만남 동의와 실제 내비 변경 승인은 차량에서 이어진다. A/B 독립 선택·선택 비공개·운전자 재확인·실행권·journal·차량 ACK는 기존 구현이 판정한다.

실제 내비 승인 화면은 **시연 이야기의 바다쉼표 카페**와 **실제 SDK 장소 소프트웨어드림센터**를 함께 구분한다. 시안의 가상 ETA를 실제 내비 정보로 표시하지 않는다. 원래 목적지와 현재 SDK 상태를 읽어 표시한다.

주행 제한에서는 캐릭터가 정지하고 `친구 한마디 듣기`·`음성 멈추기`만 표시한다. 새 통화·말 전달·만남 동의·내비 승인·최종 선택은 정차 화면과 함께 폐기된다. 정차·포커스 복귀만으로 재생이나 확인창을 재개하지 않는다. 제한 미확인 상태도 기존 차단 규칙을 따른다.

| real 기기 | 5개 통과: 실제 Console 주행→정차, DO 화면, NaviHelper·제한 리스너·TTS 조회 |

| 브라우저 | 430×932에서 상담 네 답변→곰 선택→소개 저장→여행 저장→소개 공개·여행 요약 확인→추천 상세 직접 조작, 콘솔 오류·경고 없음 |

기기 캡처는 mock의 HTTP·SDK 없는 표시 fixture다. real 검수는 주행 상태 전환과 조회만 수행했으며 이번 디자인 검수에서 실제 경유지 추가/제거를 다시 실행하지 않았다. 실차 검수·앱 심사 승인·정밀 립싱크·실시간 상대 음성 통신으로 확대 해석하지 않는다. 순정 내비 지도 배경 미표시는 계속 보류 상태다.

[검수 판정과 반복 수정](../design-qa.md)을 함께 확인한다. 원본 참조와 실제 화면은 같은 앱 영역 841×1210, 100%에서 비교했다. 130%와 확장 창은 별도 회귀다.
