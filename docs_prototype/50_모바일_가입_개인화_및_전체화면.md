# 모바일 가입 개인화와 전체 화면 전환

2026-11-15 · 실제 모바일 서비스 `service/`, 로컬 3004번.

새 가입은 **계정 생성 → 친구 선택 → AI 전달 동의 → 대화형 성향·취미 설문 → 요약 확인·수정 → 취향 저장 → 홈**으로 이어진다. 이전 구현은 계정 생성 뒤 자유 대화로 바로 들어가고 캐릭터를 마이에서만 바꿀 수 있었다.

## 동작

- 두루·루밋·모카 선택을 직접 확정하면 해당 친구로 첫 대화를 연다. 요청을 다시 보내도 같은 대화를 반환한다.
- 첫 질문과 선택적 예시 칩을 제공한다. 칩은 입력창에 초안만 채우며 직접 전송해야 한다.
- 이후 질문과 요약은 기존 OpenAI 스트리밍·도구 실행 경로로 생성한다. 서버가 가입 개인화 문맥과 완료 답변 수를 전달하며, 네 번째 답변 전에는 취향 제안·여행 제안 도구를 실행하지 않는다.
- 실제 요청 중에만 캐릭터 동작, 활동 상태와 멈추기를 표시한다. 실패·중단·응답 유실에는 본인 메시지를 유지하고 직접 재시도·전송 결과 확인을 제공한다.
- 요약은 사용자 발언으로 만든 초안이다. 관심사·여행 방식·친구에게 남길 이야기를 직접 수정하고 확인해야 프로필에 저장된다. 최신 단계·프로필 버전을 확인한 뒤 초안 확정과 완료 상태를 같은 트랜잭션으로 저장한다.
- 단계와 첫 대화·요약 연결은 계정별 `onboarding` 테이블에 보존한다. 새로고침·재로그인 후 이어갈 수 있다. 나중에 이어하기를 선택한 경우 홈에 재진입 안내를 표시한다.
- 테이블은 기존 v2 저장소에 추가로 생성한다. 기존 계정에는 자동으로 행을 만들지 않으므로 가입 절차를 강제하지 않는다. 기존 계정·원문·취향·여행·차량 데이터는 유지한다.
- 원문을 다른 여행자에게 공개하거나 차량에 전달하는 기능은 추가하지 않았다. 개인화 후 차량으로 보내는 내용은 기존 확정 여행·별명·캐릭터 계약을 따른다.

## 화면

여백 있는 대화 본문, 고정 하단 입력창, 본인 메시지 버블과 친구의 열린 본문을 사용한다. 선택한 캐릭터와 옅은 민트·하늘색을 적용하고, 과한 장식 대신 인사·실제 답변 생성·요약 확인 상태에 반응한다. 움직임 줄이기 설정을 지원한다.

모바일 너비 760px 이하에서는 가입·로그인·기록·여행 상세·차량 확인·음성 동의 창이 화면 전체를 사용한다. 안전 영역과 내부 스크롤, 닫기 동작을 유지한다. 데스크톱은 기존 중앙 모달이다.

## 검증

- 서비스 자동 테스트 99개 통과. 신규 4개 테스트는 단계·재시작 복원·중복 시작·요약 전 미저장·직접 수정·원자적 확정·계정 분리·버전 충돌·진행 중 확정 차단·이전 계정 이행과 실제 HTTP/runner 경로를 검사한다.
- 실제 OpenAI로 자유 답변 4회 → 후속 질문 → 취향 제안 → 요약 진입 → 새로고침 복원 → 직접 수정 → 저장 → 홈·마이 반영까지 확인했다. 요약의 관심사와 수정한 여행 방식이 저장됐으며, 완료 전에는 프로필 관심사가 비어 있었다.
- 320×820, 430×560, 430×932, 760×900에서 5종 dialog의 경계가 뷰포트와 일치하고 가로 넘침이 없었다. 1360×1000에서는 480~640px 너비의 중앙 모달을 유지했다.
- 320px 캐릭터 선택·요약에서 가로 넘침 없음. 라디오 선택과 방향키 이동을 확인했다. 실제 AI 대화 검수에서 콘솔 오류·경고 없음.
- 개인화 캡처는 [증거 폴더](evidence/mobile-onboarding-2026-11-15/)에 보관한다. 작업공간의 `output/playwright/mobile-ui-flow.html`은 28개 캡처를 흐름 순서로 묶은 단일 HTML이다. 여행·차량 예시는 브라우저에서만 표시했고 실제 전송하지 않았으며, HTML에 출처를 표시했다.


## 두루·루밋·모카 세 캐릭터

파도는 두루로 변경했다. 루밋은 기존 곰을 대신한 새 긴 귀 캐릭터 `rumit.png`이며, 모카는 보존된 `bear-legacy.png`로 별도 선택할 수 있다. 가입의 첫 선택과 마이, 대화·상태 문구·AI 이름을 같은 카탈로그에서 읽는다. 조사도 두루와·루밋과·모카와로 표시한다.

기존 전달과의 호환을 위해 저장 ID는 `dragon`=두루, `bear`=루밋을 유지하고 `mocha`=모카를 추가했다. 프로필·차량 공개 계약·개인 여행 수신 파서와 이미지·이름 매핑도 세 값을 지원한다. 업데이트된 차량 앱에서는 모카를 별도 리소스로 표시한다. 선택적 서버 음성도 `mocha`를 지원하며 `ELEVENLABS_VOICE_MOCHA`가 없으면 기존 곰 음성 또는 기본 음성을 사용한다.

서비스 테스트 100개 통과. 실제 신규 가입에서 모카·루밋을 선택하고 새로고침 후 저장 ID와 화면을 확인했다. 세 캐릭터가 있는 320px 선택 화면에서 가로 넘침 없음. mockDebug·realDebug 조립과 mock 단위 테스트 성공. 차량 기기 실행 검수와는 구분한다. 기존 AI 기록을 최신 이름과 이미지로 재표시해 HTML을 재촬영했으며 프로필 버전은 변경하지 않았다.
