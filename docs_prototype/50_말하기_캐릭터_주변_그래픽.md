# 말하기 캐릭터 주변 그래픽

2026-11-15. 사용자가 작은 상태 배지 외에도 ‘캐릭터가 말하는 느낌’이 보이는 그래픽을 요청했다. 기존 캐릭터 이미지는 유지하고 `AgentVoicePortrait`의 말하기 상태에 공통 효과를 추가했다.

## 표현

- 캐릭터 뒤에 부드러운 청록 빛이 천천히 커졌다 작아진다. 몸·얼굴·본문·카드 위치는 고정이다.
- 머리 양옆에는 짧은 음성 파형3개가 바깥으로 퍼지며 사라진다. 약1.8초 주기의 출력 그래픽이다. 기존 작은 파형 배지의 약2.8초 맥동을 함께 유지한다.
- 듣기는 기존의 긴 열린 곡선과 마이크, 말하기는 짧은 방사형 파형과 스피커로 구분한다.
- 작은 통화/컴팩트 캐릭터에서는 출력 원점을 조금 위로 두어 상태 배지와 겹치지 않게 했다. 그래픽은 캐릭터 이미지 뒤에 그려 실루엣을 가리지 않는다.
- 정차·포커스·시스템 애니메이션·해당 화면의 motion 허용을 모두 만족해야 움직인다. 주행에서는 약한 빛과 짧은 파형을 정적으로 표시한다. 대기/중단/쉼/사용 불가로 바뀌면 말하기 빛과 출력 파형을 제거한다.

모든 캐릭터 화면의 기존 공통 표시 경로에 적용되므로 용·곰, 답장·친구·장소·통화·MC 등에서 같은 표현을 사용한다. 실제 출력은 기존 `SpeechState.speaking`에 연결한다. 강제 상태·MC·자막 대화 캡처는 UI 시연이며 마이크/STT·실시간 상대 통신을 추가하지 않았다. 이 파형은 실제 발화 음량이나 입모양을 측정한 결과가 아니다.

## 확인 범위

[집중 캡처·영상 갤러리](evidence/speaking-graphics-2026-11-15/index.html)에 용/곰·일반/컴팩트·통화/주행·듣기/대기/쉼·MC/자막 대화를 정리했다. 빌드·표시/영상·디자인 리뷰와 실제 기능/실차 검증을 구분한다. 잔여 검증은 [36번](36_차량_UI_검증_필요_항목.md)에 남긴다.


## 빌드·캡처·리뷰 결과

- mockDebug·realDebug APK와 테스트 Kotlin 컴파일 성공. 기기/실차 전체 기능 검증을 실행한 결과는 아니다.
- 집중10개 장면을2/3분할20장으로 촬영하고 전체 PNG청크·CRC·IEND·zlib 및1682×1210·841×1210 크기를 확인했다.
- 용·곰 말하기와 주행 정적 상태를 실제 정차 Debug 앱에서 녹화했다. 녹화 길이·크기는 `motion/metadata.json`에 기록했다. 캐릭터 입모양이나 실제 마이크/음량을 측정한 시연이 아니다.
- 디자인 서브에이전트가 최신20장 원본과 녹화 프레임을 검토한 뒤 **시각·배치·애니메이션 표현 OK**로 최종 컨펌했다. 추가 필수 수정 사항 없음.
- 기존 공통164장 갤러리에서 새 말하기 효과가 보이는6개 상태×2개 창12장과 말하기/주행 영상만 갱신했다. 직전 버전은 `common-voice-2026-11-15/before-speaking-graphics`에 보존했다. 나머지 상태는 효과가 표시되지 않아 이전 확인본을 유지했다. 기존 갤러리에서 이번 집중 캡처로 가는 링크도 추가했다. GitHub push/PR은 하지 않았다.
