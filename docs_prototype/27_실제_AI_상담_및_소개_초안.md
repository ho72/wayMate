# 실제 AI 상담과 소개 초안

2026-11-14. 사용자 요청에 따라 시연 백엔드의 후속 구현으로 실제 AI 상담·소개 초안 생성을 추가했다. 기존 준비된 대화·요약 선택 모드는 유지하고, 설정·동의를 갖춘 경우 선택하는 확장이다. 추천/상대 응답·통화·내비 동작을 AI로 바꾸는 개발은 포함하지 않는다.

## 사용자 흐름

1. AI가 연결된 새 모바일 준비 화면에서 입력 대화를 OpenAI에 전송한다는 설명에 직접 동의하고 `AI와 이야기 시작`을 선택한다.
2. 고정 질문 차례 없이 원문을 보낸다. AI가 앞선 발화를 참고해 반응·필요한 후속 질문과 소개 초안을 만든다. 한 메시지 1~500자, 한 회차 최대 20회다.
3. `이 이야기로 소개 확인`에서 별명·캐릭터·AI 소개 문장과 요약 항목을 검토한다. 문장은 수정할 수 있고 요약 항목은 선택 해제할 수 있다.
4. 직접 확인한 소개를 저장한다. 이후 기존 여행·공개·추천·모바일 최종 매칭·차량 전달 절차를 적용한다. AI 응답만으로 저장·공개·매칭이 실행되지 않는다.

자유 소개와 상담 원문은 본인 모바일에서만 볼 수 있다. 차량/상대에게는 기존 계약이 지원하는 **사용자가 확인한 요약 항목**을 사용한다. 자유 서술 문장 전체를 상대에게 읽어주는 기능은 이번 구현에 없다. enum에 없는 취향을 기존 값으로 임의 변환하지 않으며, 소개 문장에 표현하더라도 요약 필드는 비어 있을 수 있다.

## 서버·계약

- [상담 계약](../mock-app/shared/contracts/consultation-v1.schema.json)은 요청·AI 초안·대화를 정의한다. [예제](../mock-app/shared/examples/consultation-v1/)와 [기존 v4 확장](../mock-app/shared/contracts/handoff-v4.schema.json)을 함께 검증한다.
- `POST /api/consultation/turns`는 web 역할과 소유 브라우저 ID를 확인한다. 본문은 `runId`, `requestId`, `expectedRevision`, `message`, `consent:true`다. 응답은 `{replayed, state}`이고 `state.consultation`으로 복원한다.
- 선택적 상태 필드이므로 기존 v4 파일을 초기화하지 않고 읽는다. 첫 요청에서 소유자와 빈 상담 세션을 저장해 AI 응답 대기 중 차량이 기본 시연 여행을 시작하는 것을 막는다.
- 원문·AI 초안은 car/operator/다른 web projection에 표시하지 않는다. 전달본 owner에도 자유 소개를 추가하지 않는다.
- `PROFILE_CONFIRM`은 최신 `consultationRevision`, 수정한 `introduction`, `confirmedSummary.summarySource=user_confirmed_ai`를 요구한다. UI는 실제 검토한 revision을 보존한다. 다른 탭에서 대화가 갱신되면 옛 초안의 저장을 잠그고 최신 초안을 다시 확인한다.
- 기존 `user_confirmed_demo` 출처도 유지한다. Android `JourneyParser`는 두 확인된 출처를 읽고 미확인 `ai_generated`는 거부한다. 시연 답변과 AI 대화를 같은 회차에 섞지 않는다.

## 호출·실패·초기화

OpenAI Responses API의 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)를 사용한다. 서버 전용 키·설정 가능한 모델·`store:false`·JSON 출력 규격을 적용하고 로컬 Ajv와 업무 조건을 다시 검사한다. 기본 모델은 [gpt-4.1-mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)이며 `OPENAI_MODEL`로 바꿀 수 있다. 다른 모델은 동일 규격의 실제 호환성을 재검증한다.

모델에는 해당 상담만 전송하고 도구·업무 실행 권한을 주지 않는다. 스키마 준수는 내용의 사실성이나 모든 민감정보 제거를 보장하지 않으므로 본인 검토와 공개 항목 선택을 유지한다. `store:false`는 응답 객체 저장을 끄는 요청이며 모든 제공자 보관 정책이 0이라는 주장은 하지 않는다.

외부 호출은 단일 업무 큐 밖에서 최대 25초 기다린다. 그동안 차량 세션·상태 보고·조회는 계속 처리한다. 응답 저장 직전에 회차·소유자·초기화/복구·차량 활성·연결·프로필·대화 버전을 다시 검사한다. 늦은 응답으로 새 회차나 확인한 프로필을 덮지 않는다.

동시 동일 요청은 한 호출로 모으고, **저장된** 응답은 메시지 ID·원문·기준 revision이 같을 때 재사용한다. 브라우저는 입력과 미확인 요청을 보존하고 사용자가 재확인할 때 같은 ID를 보낸다. 저장 전 프로세스 중단·제공자 응답 유실에서는 외부 호출의 정확히 한 번 실행/과금을 보장하지 않는다. 자동 재시도는 없다.

미설정·상위 API 오류·시간 초과·거절·미완성·형식 오류를 성공 대본으로 대체하지 않는다. 키·상위 오류 본문·요청 헤더를 브라우저/일반 로그에 반환하지 않는다. 초기화는 O01 절차로 수행하며 상담 원문/소개는 초기화 보존 기록에서 제외한다.

## 실행

Node 22.22.2에서 `mock-app/.env.example`을 `.env`로 복사하고 서버 키를 로컬로 설정한 뒤 `mock-app/`에서 `npm run start:ai`를 실행한다. 예제는 **3002번·runtime/ai-consultation-v4.json**을 사용해 기존 3000번 서버·내비 기록과 분리한다. 웹은 <http://127.0.0.1:3002>다. `.env`는 Git·소재·APK에 포함하지 않는다.

기본 `npm start`는 외부 환경 설정이 없으면 AI를 호출하지 않는다. `WAYMATE_AI_PROVIDER=openai`인데 키가 없으면 시작을 거부한다. 키 없이 기존 대본 시연을 쓰려면 `WAYMATE_AI_PROVIDER=disabled`를 사용한다.

AI 서버의 여행을 차량까지 시험하려면 같은 API 포트를 보는 APK를 별도로 빌드한다. 기본 앱은 3000번이다. `-PwaymateApiPort=3002` 검수 APK를 기본 인계본으로 혼동하지 않는다. 현재 Pleos 여정·기본 서버를 임의 초기화해 연결하지 않는다.

## 검증 기록

서버 전체 **293개**(AI 관련 20개 포함)·JVM **46개**, Android 실제 JSON 파서 기기 검사 **2개**가 통과했다. real/mock 앱과 양쪽 기기 테스트 APK 빌드, Lint 오류/치명 오류 0·경고 각 26개, 기존 v3/v4 생성 예제 무변경을 확인했다. 26번의 이전 기기 14개를 이번 실행 수에 합산하지 않는다.

실제 `gpt-4.1-mini`로 합성 여행자의 대화 **3회**를 저장했다. 앞선 취향·말투 요청·취향 정정을 반영했고, 430×932 브라우저에서 초안 수정·새로고침 보존·다른 탭의 새 대화 후 옛 확정 버튼 잠금·최신 초안 재검토·직접 저장을 확인했다. 저장 뒤에도 공개는 pending이었다. car/operator 조회에 원문과 자유 소개가 포함되지 않았고, 검수용 회차만 O01·같은 브라우저 ACK로 정리했다. 기존 3000번 서버·실제 내비 journal 16개는 그대로 유지했다.

첫 실제 호출에서 기존 JSON 계약의 `const`/enum 분기에 type이 생략된 형식이 제공자 규격에서 거부됐다. 명시적 type·enum으로 변환하고 로컬 고유성 검증은 유지하도록 수정했다. 변환 회귀와 실제 모델 응답으로 다시 확인했다. 초기 실패를 성공 호출로 합산하지 않는다.

운영 인증·다중 사용자/DB·외부 휴대폰 접속·배포·실시간 상대 통신·AI 추천·차량 STT/자유 대화는 후속이다. 이번 AI 상담이 주행 중 음성 문답을 활성화하지 않는다.
