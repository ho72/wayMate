production DrivingScreen과 고정 가상 추천을 정차 상태의 Debug 호스트에서 표시했다. 실제 차량 상태는 P/0이며 주행 제한을 변경하지 않았다. 신규 Debug 장면은 driving-places(휴식), driving-lunch(식사)다. 이 두 장면만 로컬 AgentSpeech를 생성하며 마이크·서버·내비 SDK는 생성하지 않는다. 가림·비활성·실제 차량 제한 전환 시 호스트가 화면을 폐기하고 음성을 중단한다. 캡처는 초기 대기 상태이며 마이크가 듣고 있음을 나타내는 UI는 없다.

현재 명시적 ‘추천 안내 듣기’로 고정 음원을 재생한다. 음성 인식에 따른 후보 변경/선택 및 실제 주행 전환 통합 검증은 미완료다.
