# 홈 캐릭터·일정 카드 조정 · 2026-11-15

`home-3pane.png`는 841×1210dp 앱 창, `home-2pane.png`는 1682×1210dp 앱 창이다. `*-vehicle.png`는 계기판을 포함한 각 전체 화면이다.

3분할 캐릭터 그림을 기존보다 15% 키우고 24dp 위로 이동했다. 2분할 캐릭터는 기존 크기다. 홈 일정 카드에 반투명 흰 바탕·옅은 흰 테두리·넓어진 내부 여백을 적용했다. 다른 페이지의 공통 카드는 변경하지 않았다.

가상 여행 데이터를 사용한 production `HandoffScreen`의 실제 렌더링이다. mockDebug 빌드·설치 및 두 실제 창의 표시를 확인했다. 전체 기능·기기·접근성·실차 검증 완료를 의미하지 않는다.
