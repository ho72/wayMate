# 캡처 범위·확인 기록

- 기준일: 2026-11-15.
- 범위: 현재 로컬에서 구성한 차량 UI 74개 상태의 2분할·3분할 캡처 148장. 모바일 웹·시연자 화면의 전체 캡처 모음은 아닙니다.
- 조건: 실제 정차 상태의 Pleos 분할 창에서 오프라인 가상 데이터로 화면을 그렸습니다. 화면에 나타나는 계정·여행자·장소·통화·경로 상태는 시연용입니다.
- 이 커밋은 캡처와 공유 문서를 추가합니다. 캡처를 생성한 로컬 앱 UI 수정의 전체 소스가 main에 반영됐다는 의미는 아닙니다.

## UI 구성

단독 버튼 가운데 정렬, 주요·보조 행동 분리, 큰 본문, 캘린더형 일정, 통화 전용 화면과 3분할 주요 행동 하단 고정을 적용한 화면입니다. 시연 성공·실패 및 상대 동의 장면 조작은 기본 UI에서 제외했습니다.

정보가 많은 3분할에서는 본문만 세로로 스크롤하고 주요 행동은 하단에 남습니다. 초기 캡처에 긴 일정/전체 대사/보조 행동의 일부가 보이지 않을 수 있습니다.

## 확인한 내용

- 디자인 리뷰: 서브에이전트가 15년차 차량 UI 디자이너 관점으로 검토했습니다. 실제 경력자의 인증을 뜻하지 않습니다.
- 1차: 주요 버튼 잘림·행동 묶음·중복 문구·통화 아이콘을 반려해 수정했습니다.
- 2차: 대표 13개 상태 × 2개 창의 시각·배치를 OK로 확인했습니다.
- 전체 점검: 모의 복구 화면 버튼 간격을 추가로 지적해 16dp로 수정했고, 복구 문구도 정리 맥락으로 맞췄습니다.
- 최종: 74개 상태 × 2개 창 148장의 시각·배치 OK. 제공된 캡처의 범위이며 기능/실차 인증이 아닙니다.
- PNG 148장의 크기·청크·CRC·IEND·zlib 무결성을 확인했습니다. 파일별 해시는 [무결성 기록](captures-integrity.json)에 있습니다.
- 로컬 mockDebug/realDebug 빌드 및 기존 AndroidTest Kotlin 컴파일을 확인했습니다. 기기 테스트 실행·전체 회귀·Lint·실차 검증은 실행하지 않았습니다.

## 검증 필요

실제 메시지 전송/계정 처리/내비 SDK/음성 인식, 주행 제한과 화면 복원, 오디오 포커스, 큰 글자·키보드·접근성·실차 시인성은 별도 검증이 필요합니다. 통화 화면은 준비된 음성·자막 시연이며 실제 마이크·실시간 상대 통신을 새로 연결하지 않았습니다.
