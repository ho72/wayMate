# 홈 캐릭터 위치·제목 배치 · 2026-11-15

`home-3pane.png`는 841×1210dp 앱 창, `home-2pane.png`는 1682×1210dp 앱 창이다. `*-vehicle.png`는 계기판을 포함한 각 전체 화면이다.

캐릭터 그림은 2분할에서 16dp, 3분할에서 누적 36dp(직전보다 12dp 추가) 위로 이동했다. 3분할은 1.15배 크기를 유지한다. 3분할의 제목과 보조 문구는 일정 카드 바로 위에서 오른쪽 정렬한다.

production `HandoffScreen`에 가상 여행 데이터를 넣은 실제 mockDebug 렌더링이다. 빌드·설치 및 두 실제 창 크기의 표시만 확인했으며, 전체 기능·기기·접근성 검증 완료를 뜻하지 않는다.
