# 차량 확인 패널 시각 점검 · 2026-11-15

범위는 정차 상태에서 경유지 변경을 확인하는 팝업 한 종류다. 실제 실행 권한·주행 지원·모든 팝업 접근성의 전체 감사가 아니다. 현재 실행에서 수정 전/후를 각각 새로 촬영했다.

1. 01-before.png: 기존 공통 Material AlertDialog. 확인/취소 조작은 커졌지만 416×324px의 작은 패널에 장소·동작·목적지·승인 설명이 한 문단으로 모여 있음. 중요 결정의 확인 용도와 명시적 두 행동은 유지할 가치가 있으나 차량 화면에 비해 폭과 정보 위계가 약함.
2. 02-after.png: 새 VehicleConfirmationDialog. 840×565px 패널, 큰 제목, 추가 장소/유지 목적지/변경 설명 분리, 하단 같은 폭·최소 높이 112dp의 취소/실행 행동. 02-after-detail.png는 실제 창 원본 중앙의 패널만 840×565px로 잘라 보여주는 비교용 이미지이며 색/글자/비율 보정 없음.
3. 03-in-vehicle.png: 실제 Pleos 화면의 표시 문맥. 배경 앱은 어두워지고 계기판·시스템 영역은 그대로 보임. 실제 운전이나 내비 변경은 실행하지 않음.

관찰된 개선: 카드 안 핵심 값이 구분되고, 두 행동이 하단 전체 영역에서 같은 크기로 표시됨. 원래 제목/본문/확인/취소를 받는 공통 슬롯으로 다른 확인창도 같은 틀을 사용한다.

검증 한계: 가상 표시용 미리보기에서 기존 실제 UI 컴포넌트를 렌더링한 캡처다. 작은 창/글자 130%·스크린리더·포커스·제한 전환·실차 시선/터치 정확성·실제 SDK 동작은 확인하지 않았다. 36번 문서를 따른다.
