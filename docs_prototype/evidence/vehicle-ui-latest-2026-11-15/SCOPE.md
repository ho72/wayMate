# 캡처와 main 반영 범위

2026-11-15. 두루·루밋과 별도 모카 호환을 적용한 최신 Pleos UI 검토 자료다.

## 포함

- 기존74개 화면·상태, 공통 음성 상태, 답장 정차/주행5단계, 루밋/모카 표현, 공통 버튼/확인 패널을 합쳐102개 장면을 각2/3분할로 촬영했다. 총204장이다.
- 말하기3종, 듣기3종, 처리 중, 주행 말하기/듣기 정적 등 2/3분할 영상18개와 GIF14개를 포함한다.
- 모든 촬영은 실제 정차 상태인 Pleos 에뮬레이터의 오프라인 Debug 호스트에서 수행한다. 주행 헤더와 듣기/자막/MC 상태는 미리보기 표현이다. 실제 주행 제한을 완화하거나 마이크·실시간 상대 통신을 켜지 않았다.
- 원본 창 크기: 2분할1682×1210, 3분할841×1210. ‘분할’은 계기판을 포함한 전체 차량 화면 구성을 말하며 캡처는 앱 영역만 담았다. MP4는 YUV420 호환을 위해3분할의 오른쪽 끝1px를 제외한840×1210으로 인코딩했다.
- 공통 확인 패널은 별도 Dialog 창이므로 실제 디스플레이를 앱 경계로 잘라 촬영했다. 나머지는 실제 앱 창 PixelCopy다.

## 캐릭터

두루는 기존 파란 용의 새 이름이다. 루밋은 ‘백엔드’ 채팅에서 생성한 긴 귀 크림색 PNG를 수정 없이 채택했다. 원본/생성 기록은 [이미지 문서](../../../mock-app/assets/images/design-v5/README.md)에 있다. 모카는 ‘모바일 UI’ 작업의 별도 선택을 보존한 기존 곰이며 a-03으로 표시한다. 실제 여행자 별명은 캐릭터 이름과 별개고, 캡처의 가상 사용자 이름은 ‘여행자’다.

## 소스와 검증 해석

이 갤러리는 **로컬 작업 브랜치의 최신 화면 구현**에서 촬영한 증거다. 이번 main 게시는 갤러리·README·캐릭터 리소스/이름/네이티브 로딩 변경을 포함하며, 진행 중인 모바일·백엔드 및 전체 UI 기능 코드를 모두 main에 병합했다는 뜻은 아니다. 각 기능의 서버·SDK·실차 상태와 구분한다.

캐릭터 변경은 별도 main 작업공간에서도 mockDebug·realDebug APK와 기존 테스트 Kotlin 컴파일을 확인한다. 갤러리를 촬영한 UI 작업본도 동일한 빌드/컴파일 확인을 수행한다. 기기 테스트 실행·STT·실시간 통신·실차 인증을 뜻하지 않는다. 남은 항목은 [검증 필요](VALIDATION.md)에 따로 기록한다.

파일별 PNG 무결성/크기/해시는 `captures-integrity.json`, 영상 정보/해시는 `motion/metadata.json`, 소스·자산 식별 정보는 `source-snapshot.json`에 기록한다. 이전148장 갤러리는 과거 기록으로 보존하고 최신 링크를 연결한다. PR은 만들지 않는다.

공유 기기 검증과의 충돌을 피하기 위해 전체 재촬영은 같은 Pleos AVD의 읽기 전용 전용 인스턴스와 별도 applicationId를 사용했다. 모든204장과18개 영상은 공통 색상 토큰까지 고정한 하나의 UI 소스 스냅샷에서 만들었다. 앱 설치 식별자와 빌드 출력만 분리했고, Debug 캡처 대기만1500ms에서700ms로 줄였다. 실제 화면 애니메이션과 차량 제한은 바꾸지 않았다.

최종 디자인·브라우저 확인 결과는 [검토 기록](REVIEW.md)에 있다.
