# 검증 필요 — 차량 UI

이 문서는 빌드·캡처·시각 리뷰와 실제 기능 검증을 구분한다.

- 실제 마이크/STT·OEM 입력 진입·수음 중에만 듣기 표시·소음/무응답/취소/정정/타임아웃·입출력 중첩 방지 연결은 필요하다. 듣기/처리는 강제 UI 시연이며 마이크는 꺼져 있다.
- 음성 선택→수신자/문장 재확인→별도 명시 전송 승인→현재 binding·중복 방지→ACK 후 완료, 늦은 결과/화면 복원 시 자동 전송·자동 재생 없음은 실제 서버로 검증한다.
- 실제 CarUxRestrictions와 OEM의 메시지/전사/콘텐츠/애니메이션 제한·주행 전환·차단·정차 복귀, 오디오 포커스·전화/내비 우선순위·창 비활성·프로세스 복원을 검증한다. 주행 표현은 정적이고 기존 기능 제한을 유지했다.
- 130% 글자·작은 높이·긴 문구·여러 스레드·일정/키보드·TalkBack 읽기/탐색/선택·live region·최소 조작 영역과 고정 버튼 도달성·실차 가독성을 확인한다.
- 두루/루밋/모카 선택·여행 전달/수신·기존 avatar ID 호환·루밋 귀 끝/배지/음성 호 겹침과 Fit 비율을 실제 계정·차량 연결에서도 검증한다. 캡처는 가상 데이터로 선택 상태를 직접 구성한 것이다.
- 실제 내비 SDK 실행·동의/취소/실패·원래 목적지 보존·경유지 정리·계정/연결 해제·통화/MC 별도 동의·서버 결과 미확인 잠금은 통합 검증이 필요하다.
- Lint·전체 기기/실차 회귀와 이전 자동화 접근성 트리 갱신 이슈는 별도다. 디자인 OK를 기능·안전·인식/통신 검증 완료로 확대하지 않는다.
