# 현재 헤더 표시 캡처 · 2026-11-15

현재 HandoffScreen·VehicleExtraScreen·DrivingScreen을 Debug 미리보기에서 가상 여행 상태로 렌더링한 확장 창 캡처다. 실제 차량 주행 상태는 바꾸지 않았다. 디자인·배치는 수정하지 않고 Debug 촬영 진입과 PixelCopy 저장만 추가했다.

home.png는 정차 본인 여행 홈, request.png는 정차 장소 질문, driving.png는 현재 주행 간편 화면 컴포넌트다. 준비 음원 재생은 연결하지 않은 가상 표시 상태다. *-header.png는 동일 원본 위쪽 180픽셀을 자른 비교 이미지이며 문구·색상·크기 보정은 없다.

화면 확인용 캡처이며 실제 차량 상태 전환·음성 기능·통합 검증 완료를 의미하지 않는다. 남은 검증은 36번 문서를 따른다.
