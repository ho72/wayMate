# 캐릭터 공통 음성 상태와 맥동

2026-11-15. 답장 확인에서 확정한 상태 표시를 모든 캐릭터 화면으로 확장했다. [48번 답장 UI](48_답장_정차_주행_및_음성_상태_UI.md)의 입력 미연결·주행 제한 범위를 유지한다.

## 공통 적용

`AgentVoiceVisual`을 모든 캐릭터의 단일 표시 경로로 사용한다. `AgentCharacter`의 실제 호출은 이 공통 컴포넌트 한 곳에만 남는다. 앱 루트의 `SpeechState`와 화면의 `InteractionMode`를 전달하며, 해당 화면이 별도 출력 상태를 갖는 경우 이를 명시한다.

적용 화면은 여행 준비/홈, 내 친구, 친구 소개·질문·답변·문장 선택·답장·쉼, 장소 질문·추천 목록·상세·일정, 경로 확인·요청/결과·정리/복구, 만남, 마무리/기록, 계정 여행, 자막 대화/MC, 통화, 주행 홈/추천이다.

- 상태 위치·아이콘·파형·입력 곡선·처리 점·대기/쉼을 공통 사용한다. 기존 말풍선의 과업 의미는 제목과 카드에서 전달한다. 공통 말하기 문구는 ‘말하고 있어요’이며 답장 화면은 ‘답장을 읽고 있어요’라는 문맥을 유지한다.
- 정차: 실제 출력 상태와 그래픽 연결. 입력은 STT 미연결이므로 실제 듣기 표시를 자동으로 켜지 않는다. 자막 대화/MC와 강제 상태 미리보기는 ‘음성 UI 시연 · 마이크 꺼짐’을 표시한다. 자막 대화는 상대 대사에서 말하기, 내 차례에서 듣기, 쉼에서 일시정지로 구분한다.
- 주행: 실제 차량 제한에 따라 기존 허용된 홈/추천만 표시하며 같은 상태 그래픽을 **정적**으로 표시한다. 사회적 메시지·자막 대화·통화 화면의 기존 주행 차단을 유지한다. 모드 헤더와 음성 상태는 각각 독립적이다.
- 차단: 입력/출력 대기 시연을 노출하지 않고 ‘상태 확인 후 이어가요’로 전환한다.
- 통화: 통화 상태/실제 동의/샘플 재생 계약은 유지한다. 공통 배지를 표시하고 실제 현재 샘플 문장과 일치하는 발화자에게만 파형을 붙인다. 실시간 상대 마이크를 나타내지 않는다.

## 사용자가 요청한 커졌다 작아지는 움직임

캐릭터 몸과 본문은 고정한다. 정차에서 활성 상태 그래픽만 느리게 맥동한다.

| 그래픽 | 변화 | 주기 |
| --- | --- | --- |
| 말하기 원형 배지 | 1.00 → 약 1.06 → 1.00 배율, 작은 파형 높이 변화 | 한 방향 1.4초, 왕복 약 2.8초 |
| 듣기 원형 배지 | 1.00 → 약 1.06 → 1.00 배율 | 동일 |
| 듣기 열린 곡선 | 약 4.8% 범위로 크기와 불투명도 변화 | 동일 |
| 처리 중 세 점 | 불투명도 변화 | 동일 |
| 대기·쉼·중단·사용 불가 | 움직임 없음 | — |

움직임은 그래픽 변환으로만 적용해 주변 글자/카드/버튼을 밀지 않는다. 정차·창 포커스·시스템 애니메이션 허용·해당 화면의 motion 허용을 모두 만족해야 움직인다. 주행/차단/포커스 상실에서는 즉시 정적인 형태로 렌더링한다. 실제 수음 크기나 정확한 음성 진폭을 나타내는 그래픽이 아니다.

## 실제 연결과 검증

실제 STT, 마이크 세션, 음성 인식 결과 해석/재확인/전송 승인, OEM 주행 허용, 오디오 포커스·복원·접근성·실차 검증은 [검증 필요 문서](36_차량_UI_검증_필요_항목.md)에 남긴다. 빌드·정차 Debug 캡처·시각 리뷰를 입력 연결 완료로 해석하지 않는다.

## 확인 기록

- mockDebug·realDebug APK 빌드와 `compileMockDebugAndroidTestKotlin --offline` 성공. 전체 기기 테스트 실행을 뜻하지 않는다.
- 기존74개 화면과 대표 상태8개를 각2/3분할로 촬영했다. 대표 상태는 내 친구/장소 질문의 말하기·듣기, 주행 추천 말하기·듣기 정적 시연, 통화 발화자, 긴 음성 사용 불가 문구다.
- 실제 정차 Debug 앱에서 말하기·듣기 맥동과 주행 정적 표현을 녹화했다. [말하기·듣기 GIF 비교](evidence/common-voice-2026-11-15/motion/speaking-listening.gif), [말하기 영상](evidence/common-voice-2026-11-15/motion/speaking.mp4), [듣기 영상](evidence/common-voice-2026-11-15/motion/listening.mp4), [주행 정적 영상](evidence/common-voice-2026-11-15/motion/driving-static.mp4). 영상 길이·크기는 `motion/metadata.json`, 압축 영상 프레임의 참고 비교는 `motion/frame-comparison.json`에 기록했다. 압축 오차를 실제 레이아웃 움직임으로 판정하지 않는다.
- 디자인 리뷰에서 일반3분할 배지와 용의 꼬리가 가까운 점을 지적받아 작은 영역36dp/일반 영역60dp 바깥 간격으로 수정했다. 3분할 주행의 캐릭터가 남는 높이를 채우던 부분은300dp로 고정하고 카드와 함께 가운데에 정렬했다. 2분할과 대표 상태의 시각·맥동은 OK를 받았다.
