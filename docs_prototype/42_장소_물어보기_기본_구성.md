# 장소 물어보기 기본 구성

2026-11-15. VehicleExtraScreen의 REQUEST(WF-034) 화면에 확정한 기본 구성을 적용했다.

- 홈·내 친구 대화와 같은 CompanionScene 및 CompanionInfoCard를 사용한다. 2분할은 좌측 캐릭터·우측 제목/설명 카드/주요 버튼, 3분할은 캐릭터 아래 가운데 제목/설명 카드/주요 버튼이다.
- 캐릭터는 2분할 460dp·위로 16dp, 3분할 260dp 영역에서 1.15배·위로 36dp의 공통 규격을 사용한다. 전체 콘텐츠의 높이에 따른 중앙 배치도 공통이다.
- 설명은 반투명 카드 안에 넣었다. 제목의 좌우 기준선은 카드 본문과 동일한 30dp다.
- ‘30분 쉴 곳 물어보기’와 ‘점심 장소 물어보기’를 청록/민트 버튼으로 나란히 배치했다. 기존 chooseQuery(false/true)를 사용하며 정차/활성 상태 확인 전 또는 미확인 요청 잠금 중에는 비활성이다.
- REQUEST의 ‘시연 조건 선택’과 ‘내 친구 홈으로’를 제거했다. 복귀는 공통 이전 버튼과 기존 시스템 뒤로가기를 사용한다. 다른 페이지의 시연 설정·복귀는 변경하지 않았다.
- 시작 화면의 기술적 미리보기 설명과 화면 목록 진입은 기본 화면에서 제외했다. 장소 후보와 내비 결과의 가상/모의 성격은 그대로이며 실제 서비스·SDK 연결로 변경하지 않았다.
