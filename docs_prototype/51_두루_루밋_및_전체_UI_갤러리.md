# 두루·루밋 교체와 전체 차량 UI 갤러리

2026-11-15.

- 기존 파란 용의 이름을 **두루**로 표시한다.
- ‘백엔드’ 채팅에서 생성한 긴 귀 크림색 PNG를 **루밋**으로 채택했다. 원본을 변경하지 않았고 SHA256은 `90a4d95474769366e2a250e774f12966936b2c31aa10fda729b5ec3fe94957f9`다.
- 이전 곰은 별도 **모카** 선택(a-03)으로 보존한다. 루밋(a-02/b-01)과 이미지가 섞이지 않게 분리했다.
- 상태 배지에 캐릭터 이름을 붙이고, 여행자 별명은 별도로 유지한다. Debug 캡처의 가상 여행자 이름은 ‘여행자’다. 기존 사용자 데이터의 별명을 일괄 변경하지 않았다.
- 루밋의 긴 귀를 고려해 컴팩트 상태 배지를 조금 더 바깥에 둔다. 본체는 고정하고 말하기 빛/짧은 파형, 듣기 긴 호/마이크를 공통 사용한다. 주행 표현은 정적이다.

## main 반영 범위

main에는 최신 검토 갤러리·루트 README 링크와 캐릭터 이미지/표시 이름/네이티브 로딩 변경을 반영한다. UI 작업본과 main 반영용 캐릭터 변경은 별도 작업공간에서 mockDebug·realDebug APK 및 테스트 Kotlin 컴파일을 확인한다. 진행 중인 모바일·백엔드와 전체 UI 기능 코드까지 모두 main에 병합하는 작업과는 구분한다. 실제 STT·실시간 통신·실차·SDK 통합 검증은 별도다. PR은 만들지 않는다.

전체 재촬영은 최신 공통 색상 토큰을 포함한 하나의 소스 스냅샷을 고정하고, 전용 에뮬레이터/별도 Debug applicationId로 수행했다. 공유 기기의 백엔드 설치 테스트와 조율해 캡처를 우선했다. 각 원본과 영상의 크기·무결성·해시는 갤러리 JSON 기록을 따른다.

최종 디자인 리뷰는 전체204장/18영상 범위에서OK다. HTML 검색·필터·양쪽 영상 재생과 데스크톱/모바일 폭을 확인했다. [검토 기록](evidence/vehicle-ui-latest-2026-11-15/REVIEW.md).
