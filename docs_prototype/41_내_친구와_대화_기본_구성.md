# 내 친구와 대화 기본 구성

2026-11-15. 본인 캐릭터와 대화하는 ContentScreen의 friend 화면에 확정한 기본 구성을 적용했다.

- 홈과 대화가 CompanionScene의 배치·캐릭터·제목 및 CompanionInfoCard를 공유한다. 2분할은 좌측 캐릭터·우측 제목/카드/행동, 3분할은 캐릭터 아래 가운데 제목/카드/행동이다.
- 캐릭터는 2분할 460dp·위로 16dp, 3분할 260dp 영역에서 1.15배·위로 36dp다. 본문의 위 여백과 캐릭터 영역은 홈과 같은 규격이며 긴 카드나 보조 기능 펼침에 따른 콘텐츠 높이는 달라질 수 있다.
- 대화와 일정 관련 안내를 반투명 카드 안에 넣었다. 제목은 카드 본문과 같은 좌우 30dp 기준선을 사용하며 3분할에서는 가운데 정렬이다.
- 장소 질문·일정 안내는 청록/민트 주요 버튼 두 개로 나란히 배치했다. 기존 콜백·활성 조건을 사용한다.
- 후속 사용자 요청으로 기본 대화의 하단 ‘음성 안내’·‘내 일정 보기’와 해당 펼침 UI를 제거했다. 일정 진입은 주요 ‘내 일정과 안내 확인’ 버튼으로 제공한다. 재생 중 낭독 중단, 미확인 전송 재시도/중단 및 상대 연결 시 콘텐츠 목록 복귀는 유지한다.
- 이전은 공통 VehicleBackButton으로 통일했다. 배경·테두리 없이 34sp 글자와 196×96dp 이상의 누름 영역을 사용한다. 기본 대화에서는 이전을 본문 위에 배치하여 이전 행 때문에 캐릭터가 아래로 밀리지 않게 했다. 중복 홈 복귀 텍스트는 같은 기능의 이전으로 통합했다.
- 상대 소개·질문·메시지·통화·잠깐 쉬기·완료 및 차단 화면은 기존 구성을 유지한다. 공통 이전 스타일은 해당 헤더를 사용하는 화면에도 적용된다.

mockDebug 빌드·설치 및 가상 여행의 두 실제 창 표시를 확인했다. [최신 캡처](evidence/friend-clean-v4-2026-11-15/README.md)에서 카드와 주요 버튼 두 개가 초기 화면에 함께 표시된다. 기능·접근성·기기 회귀는 [36번](36_차량_UI_검증_필요_항목.md)에 별도 기록한다. PR은 생성하지 않는다.
