# 홈 분할 레이아웃

2026-11-15. 계기판을 포함한 3분할을 권장하고, 2분할도 지원하는 방향으로 홈을 조정했다. 앞으로 UI 변경 캡처는 두 분할의 앱 화면을 함께 제공한다.

## 확정한 기본 화면 구성

사용자가 `home-heading-v5` 구성을 기본 화면 틀로 확정했다. 이후 기본 화면을 손볼 때는 이 배치를 기준으로 상태별 내용을 교체한다.

- 공통 헤더의 로고·정차/주행 표시·현재 페이지 태그 위치를 유지한다.
- 2분할은 좌측 캐릭터, 우측 제목·보조 문구 → 정보 카드 → 주요 버튼의 구성을 유지한다.
- 3분할은 캐릭터 → 가운데 정렬 제목·보조 문구 → 정보 카드 → 주요 버튼의 세로 구성을 유지한다.
- 상황에 따라 캐릭터 대사, 제목·보조 문구, 카드 안 정보, 버튼 문구·동작·활성 상태를 바꾼다. 기본 간격·정렬·카드 스타일·버튼 규격은 공통으로 사용한다.
- 이 결정은 기본 화면의 구성 기준이다. 모든 상세 화면을 이 틀로 전환하거나 새로운 상태별 동작을 구현한 것으로 기록하지 않는다. 필요한 상세·확인·입력 화면은 각 흐름에서 별도로 다룬다.
- 정차·주행 표시와 실제 입력 허용은 기존 상태 정책을 따른다. 주행 음성 문답 등 미구현 기능은 별도 구현·검증 대상으로 유지한다.

구성 확정 시점에는 기준만 기록했다. 이후 [41번](41_내_친구와_대화_기본_구성.md)에서 홈과 내 친구 대화가 공통 컴포넌트를 사용하도록 묶었다. 제목의 좌우 30dp 기준선을 카드 본문과 통일했다.

- 3분할: 앱 창 841×1210dp. 캐릭터 배치 영역 높이 260dp에서 그림만 1.15배(약 299dp)로 키우고 36dp 위로 이동했다(직전보다 12dp 추가). 아래에 다음 일정과 주요 행동 두 개를 배치한다.
- 2분할: 앱 창 1682×1210dp. 캐릭터와 일정·주요 행동을 좌우에 배치하고 각 영역의 세로 중심을 맞춘다. 여행 중 캐릭터 영역은 460dp이며 그림만 16dp 위로 이동했다.
- 고정 헤더 아래 본문 시작 여백을 3분할 140dp, 2분할 120dp로 늘렸다. 말풍선과 캐릭터 사이 배치 간격은 60dp다.
- 사용자의 분할 지정 정정에 따라 2분할의 ‘우리, 어디까지 왔을까?’ 제목과 보조 문구는 우측 일정 카드 바로 위에 왼쪽 정렬한다. 3분할은 캐릭터 아래·일정 카드 위에서 가운데 정렬한다.
- 홈 일정 카드는 흰색 불투명도 38%, 흰 테두리 55%, 모서리 32dp로 배경과 부드럽게 연결했다. 내부 좌우 30dp·상하 28dp·행 간격 14dp, 표제 20sp를 적용했다. 다른 페이지의 공통 카드는 변경하지 않았다.
- 사용자의 후속 요청으로 ‘내 일정 자세히 보기’·‘여행 관리’ 버튼과 해당 홈 펼침 영역을 제거했다. 다른 일정·결말 화면이나 서버 계약을 삭제한 것은 아니다.
- 일정 카드 터치 진입·음성 일정 응답·별도 관리 메뉴는 아직 구현하지 않았다. 배치 제안 이후 사용자가 우선 두 버튼 제거를 요청했으므로 이번 UI에는 넣지 않았다.
- 본문 내용이 가용 높이보다 길어지면 스크롤할 수 있도록 최소 콘텐츠 높이를 계산한다.

실제 production `HandoffScreen`에 가상 여행 데이터를 넣어 mockDebug에서 표시했다. APK 빌드와 두 실제 창 크기의 캡처만 확인했다. 실제 계정·음성·서버·내비 실행을 검증한 결과가 아니다.
