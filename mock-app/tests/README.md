# 검증 코드 위치

현재 자동 테스트 코드는 없습니다. 서버·계약을 구현할 때 실제 테스트와 실행 스크립트를 추가합니다. 폴더나 테스트 계획의 존재를 테스트 통과로 표시하지 않습니다.

- `contracts/`: 공통 schema와 역할별 JSON 예제의 일치·잘못된 봉투 거부.
- `server/`: 상태 전환·역할별 projection·버전·명령 중복·영수증·순차 저장·취소·회차.
- `integration/`: 실제 HTTP 준비·전달·차량 ACK·재접속 흐름. 실제 에뮬레이터 검수 여부를 구분.

차량 JVM 테스트는 `vehicle/app/src/test/`에 둡니다. 실제 제한·음성·내비·창 크기는 에뮬레이터 증빙으로 보완합니다. 구체적인 Q와 별도 서비스 가설 V는 저장소 `docs/05_제작_일정_업무_및_검수표.md`가 기준입니다.
