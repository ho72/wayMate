# 전달 서버 · SERVER 담당

Node 표준 HTTP·파일 API와 고정된 Ajv 검증기로 본인 여행 전달을 구현했습니다. `../`에서 `npm start`로 실행합니다. API·지원 명령·오류·실행 범위는 [07 첫 전달](../../docs/07_첫_전달_실행_및_계약.md), 전체 후속 명세는 [04 연동 계약](../../docs/04_개발_및_연동_명세서.md)을 따릅니다.

| 파일·경로 | 책임 |
|---|---|
| `main.mjs`, `http/server.mjs` | 로컬 바인딩·역할/view 확인·정적 허용 목록·JSON HTTP |
| `commands.mjs` | 읽기/쓰기의 단일 순차 큐·중복 조회·버전 검증·영수증·저장 조정 |
| `domain/handoff.mjs` | 프로필·비공개·고정 여행·전달·세션·제한·ACK 계산 |
| `state.mjs`, `validation.mjs` | 새 저장소·기존 저장소 무결성·공통 schema 검증 |
| `store.mjs` | 단일 writer lock·임시 파일 fsync·rename·디렉터리 fsync |
| `projections/state.mjs` | web/car의 본인 정보와 허용 행동, 비소유 웹 정보 숨김 |
| `fixtures/trip.mjs` | 강릉 고정 여행 원본. 정적 URL로 제공하지 않음 |

상태·영수증은 `runtime/state.json`에 함께 저장합니다. 같은 경로의 서버 중복 실행은 lock으로 거절합니다. 교체 전 실패는 메모리를 반영하지 않고, 교체 후 결과 불확실은 503으로 쓰기를 중단합니다. 손상 파일은 자동 초기화하지 않습니다. 비정상 종료의 lock 정리·새 시연 데이터 준비 절차는 07을 참고하세요.

인증·다중 사용자·DB 확장·외부 배포 기능은 포함하지 않습니다. 역할 헤더와 클라이언트 ID는 로컬 시연용 식별입니다. 현재 영수증은 자동 삭제하지 않으며 장시간 운영용 저장 방식은 후속 작업입니다.
