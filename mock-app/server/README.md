# 전달 서버 · SERVER 담당

현재는 책임 디렉터리와 시연 원본 위치만 준비한 상태입니다. HTTP 서버·상태 저장·API는 아직 구현하지 않았습니다. [연동 계약](../../docs/04_개발_및_연동_명세서.md)과 [분담 가이드](../../docs/06_개발_아키텍처_및_분담_가이드.md)를 기준으로 구현합니다.

| 위치·예정 파일 | 책임 |
|---|---|
| `main.mjs`, `http/` | HTTP 조립·라우팅·역할 헤더·입출력. 정적 제공은 web와 허용 소재만 |
| `commands.mjs` | 하나의 순차 큐, 중복 영수증·회차·버전·역할·대상·제한 검증, 저장·응답 조정 |
| `domain/` | 프로필·여행·연결·콘텐츠·만남·내비·결말·초기화의 상태 계산 |
| `state.mjs` | 새 저장소·회차의 기본 상태. 기존 파일 오류를 기본값으로 덮지 않음 |
| `store.mjs` | 상태·영수증·journal을 같은 단위로 원자적 저장 |
| `projections.mjs`, `projections/` | web/car/operator의 현재 허용 정보·행동을 필터링 |
| `fixtures/` | 전체 시연 원본. CONTENT와 문장·소재 내용을 맞추되 client에 원본 배포 금지 |

의존 방향은 HTTP → 공통 명령 조정 → 도메인 계산 → 저장 → 역할별 응답입니다. 도메인마다 별도 큐·파일 저장을 만들지 않습니다. 허용 목록과 실제 명령 실행은 같은 조건 함수를 사용합니다. SDK 물리 호출은 차량이 수행하며 서버 조회로 실행시키지 않습니다.

첫 인계물은 공통 schema·역할별 예제·health·최소 프로필/여행/전달/ACK API와 관련 검증입니다. 관련 W01~W05의 전체 완료 조건은 05번 문서에서 확인합니다.
