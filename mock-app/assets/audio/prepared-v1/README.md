# 준비 음성 v1

한국어 고정 대사를 macOS `say`로 생성한 합성 음성 35개. Yuna(A·캐릭터·안내), Eddy 한국어(B), 분당 165 단어, AAC 48kbps M4A. 실시간 사람 통화·마이크 녹음·서버 생성 음성이 아니다. 외부 API나 인증 키가 필요 없다.

`index.json`은 NFC 자막의 SHA-256과 음원을 연결한다. 통화·만남 재연·두 결말·캐릭터 답변을 포함한다. 차량은 일치하는 파일을 우선 재생하고, 파일이 없는 문장은 사용 가능한 Android TTS로만 읽는다. 둘 다 없으면 실패 상태·자막을 표시한다. 실제 MediaPlayer 시작/완료 콜백에 발화 동작을 연결하며, 포커스 상실·가림·제한에서 중단하고 자동 재개하지 않는다.

재생성: macOS에서 `node scripts/generate-prepared-speech.mjs`. 기존 파일은 재사용한다. 음성 변경 시 음원과 manifest를 함께 갱신하고 기기 재생 검사를 다시 실행한다. `say`의 해당 음성이 설치되어 있어야 한다. APK 빌드는 생성 없이 버전 관리된 파일을 복사한다.

주행 간편 모드 전용 한마디를 포함해 35개다. 주행 화면은 실제 발화 중에도 캐릭터를 정적으로 유지하며, 모드 전환·상태 만료·포커스 상실 시 중단한다. 음성 인식이나 실제 상대 통신을 제공하지 않는다.
