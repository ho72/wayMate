2026-11-11 사용자가 채택한 wayMate 캐릭터의 외형 참고 이미지입니다. 생성 도구는 built-in ImageGen이며 생성 프롬프트·출처·무결성 값은 `reference.json`에 기록합니다.

- `reference.png`: 파란 피부·밝은 배·큰 눈·작은 뿔을 가진 드래곤의 3D 렌더 스타일. 앱·디자인 작업의 외형 기준입니다.

- v3의 `a-01`에 명시적으로 연결했습니다. `shared/assets-manifest.json`·웹 선택명/미리보기·차량 AgentCharacter·Gradle 소재 복사를 함께 갱신했습니다. `a-02`는 기존 햇살 도형입니다. v2 기록은 소급 변경하지 않습니다.
- 주차용 캐릭터 연출과 주행 중 기능 제한은 기존 문서 기준을 유지합니다.
