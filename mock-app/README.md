# wayMate 앱 실행

현재 범위는 **v3 자유 입력 → 직접 확인한 소개값 → 고정 여행 저장 → prepared_trip 전달/차량 직접 시작 → 블루 드래곤 홈·복원**입니다. [10 실행·검증 기록](../docs/10_v3_여행_준비_차량_홈_및_내비_시험.md)에 계약·검증·미완료 범위를 정리했습니다. 전체 목표는 [04](../docs/04_개발_및_연동_명세서.md)·[08](../docs/08_목업_화면_설계서_및_와이어프레임.md), 협업 경계는 [06](../docs/06_개발_아키텍처_및_분담_가이드.md)을 따릅니다.

## 웹·서버

이 디렉터리에서 Node **22.22.2**를 사용합니다. nvm 사용자는 `nvm install`·`nvm use`로 `.nvmrc`를 적용합니다.

```sh
npm ci --ignore-scripts
npm start
```

[여행 준비 화면](http://127.0.0.1:3000)에서 질문별 답변 전송 → 별명/외형/소개값 확인 저장 → 여행 계획 저장 → 차량에 전달 준비를 누릅니다. 예시 칩은 초안만 넣으며 직접 전송해야 합니다. 소개값은 자동 선택하지 않습니다. 첫 저장 브라우저의 클라이언트 ID를 유지하세요.

서버는 `127.0.0.1:3000`에 바인딩하고, 차량은 `http://10.0.2.2:3000`을 사용합니다. v3는 `runtime/state-v3.json`을 사용하며 기존 `state.json`·v2 예제·v2 브라우저 pending을 보존합니다. 공개 서버·실제 휴대폰 접속은 제공하지 않습니다.

## 차량

[차량 안내](vehicle/README.md)대로 `mockDebug`를 실행합니다. **웹에서 준비한 여행 불러오기**는 prepared_trip ACK를 저장한 뒤 홈으로 갑니다. **저장된 준비 확인하고 시작**은 확인한 core 버전으로 직접 시작하며 모바일 ACK를 만들지 않습니다. 준비가 전혀 없을 때만 별도 확인 후 기본 시연 계획을 만들 수 있습니다. 정차·제한 확인·활성 화면이 필요합니다.

차량 시작 뒤 웹 준비 변경은 서버에서 차단합니다. 같은 차량의 새 세션은 최신 제한을 보고한 후 홈을 복원합니다. 캐릭터 a-01은 승인한 정적 드래곤, a-02는 기존 햇살 도형입니다. 애니메이션·음성은 아직 없습니다.

## 검증

```sh
npm test
npm run examples
```

테스트는 임시 상태·포트를 사용하며 실행 중인 시연을 바꾸지 않습니다. `examples`는 `shared/examples/v3/`만 재생성합니다. 기존 루트의 v2 예제는 역사 기록입니다.

| 경로 | 책임 |
|---|---|
| `shared/contracts/`, `shared/examples/` | 활성 v3 계약·golden과 보존된 v2 |
| `server/http/`, `commands.mjs`, `store.mjs` | 역할·순차 명령·버전·영수증·원자 저장 |
| `server/domain/`, `server/projections/` | 전이·활성화·원문 비노출 |
| `web/` | 탑승 전 자유 입력·소개/계획 확인·응답 유실 복구 |
| `vehicle/app/src/main/` | Compose 시작/홈·Repository·실제 차량 제한 |
| `vehicle/app/src/realDebug/` | 제품과 분리한 실제 NaviHelper 시험 |
| `assets/`, `shared/assets-manifest.json` | 승인 이미지·외형 ID 연결 |
| `runtime/` | 개인 상태·증거, Git 추적 제외 |

실제 내비는 연결·조회까지 확인했고, 시험 목적지 좌표 불일치로 경유지 추가/제거는 미실시입니다. 추천·매칭·공개 승인·콘텐츠·만남·두 결말·O01·업무 초기화·주행 음성은 후속입니다. 전체 v3와 Q28 완료를 뜻하지 않습니다.
