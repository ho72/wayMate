# 모바일·시연자 웹 · WEB 담당

현재 HTML·API client·화면 코드는 구현 전입니다. [03 화면](../../docs/03_화면_및_상호작용_설계서.md), [04 API](../../docs/04_개발_및_연동_명세서.md), [06 분담](../../docs/06_개발_아키텍처_및_분담_가이드.md)을 기준으로 만듭니다.

| 위치 | 책임·구현 대상 |
|---|---|
| `index.html`, `app.js`·예정 | 모바일 진입·화면 조립 |
| `views/` | M01 온보딩·프로필, M02 여행, M03 추천, M04 연결·전달 |
| `operator.html`, `operator.js`·예정 | 별도 O01 진입·조립 |
| `operator/` | B 응답·모의 내비 결과·시간 전환·초기화·재시연 UI |
| `shared/` | HTTP client·조회 취소·미확인 명령 영수증 확인·공통 표시 |

모바일과 O01은 같은 서버와 client 기반을 사용하되 역할·허용 행동을 분리합니다. O01은 임의 성공값이나 새 동의를 만드는 범용 상태 편집기가 아닙니다. 현재 actionBindings의 target·payload를 사용하고 서버가 실행 조건을 다시 확인합니다.

화면별 파일·스타일을 나눠 작업하고 전역 CSS 수정은 소비 화면과 함께 확인합니다. 화면에서 서버 fixture를 직접 import하지 않으며 역할별 예제만 개발 Preview에 사용합니다. 서버 상태·영수증을 저장하기 전 성공을 표시하거나 localStorage를 업무 상태의 기준으로 사용하지 않습니다. 모달·초안·펼침은 로컬 UI 상태입니다.
