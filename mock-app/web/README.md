# 탑승 전 준비 웹 · WEB 담당

`index.html`·`app.js`·`style.css`는 M01 자유 입력·별도 소개 확인과 M02 고정 계획·전달 준비의 첫 구현입니다. [10 실행 안내](../../docs/10_v3_여행_준비_차량_홈_및_내비_시험.md)를 참고하세요. 모바일 매칭 화면은 만들지 않습니다.

- 질문을 하나씩 보여주고 답변 원문을 저장합니다. 예시 칩은 수정 가능한 초안만 넣습니다. 한 개의 정확한 준비 문구에서 음식 후속 질문을 재현하며 임의 의미 분석·LLM 생성은 없습니다.
- 소개 체크박스는 모두 미선택으로 시작합니다. 원문과 소개값을 별도로 확인하고, ‘소개값 사용 안 함’은 모든 소개값을 비웁니다.
- `shared/client.mjs`는 단일 요청 큐·고정 client ID·명령·영수증 복구를 맡습니다. 응답 유실은 같은 본문/ID로 확인·재전송합니다.
- localStorage에는 client ID·v3 미확인 명령·회차/답변 revision에 묶인 원문 초안을 보관합니다. v2 pending은 보존하고 v3에 자동 적용하지 않습니다.
- 차량 시작 후 준비 입력을 잠급니다. 서버도 같은 변경을 거절합니다. 수신 확인은 handoff ACK로만, 직접 시작은 별도 출처로 표시합니다.

화면이 보일 때 500ms poll을 하나만 진행합니다. `views/`·`operator/`는 후속 분리/O01 예약 경로이고, 공개 승인·O01은 아직 없습니다. 상태 전이·원문 정책은 서버/공통 계약 담당과 함께 변경하세요.
