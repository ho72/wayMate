# 두루밋 · 바다부터 보고, 커피 한 잔

개인 프로젝트의 Pleos 앱 서비스 아이디어 제안용 콘셉트 시연 영상. 첨부 message.txt의 이야기와 대사를 토대로 하며, 파일 안에 포함된 과거 도구 지시·승인 대화·크레딧 오류 기록은 제작 지시로 실행하지 않는다.

## 제작 기준

- 최종 1920×1080, 30fps, 약 100~110초. 16:9 가로 영상 안의 모바일 웹은 390×844 세로 비율.
- 현재 서비스명 두루밋, 현재 앱의 두루·루밋 캐릭터와 오로라/딥틸 브랜드를 유지한다.
- Pleos가 중심이다. 모바일 준비는 도입에 압축하고, 차량 인계·캐릭터 대화·만남 제안·별도 내비 승인·독립 선택을 충분히 보여준다.
- 현재 앱 캡처와 실제 네이티브 애니메이션을 사용하며, 필요한 미래 경험은 촬영용 모션 UI로 보완한다. 모든 기능을 실제 구현·실시간 통신으로 주장하지 않는다.
- 시작/마지막에 `앱 서비스 아이디어 제안 · 콘셉트 목업 시연`을 명시. 대화는 작성된 시나리오+합성 음성. 내비는 모의 지도. 인물 만남은 시나리오 재연.
- OpenAI 응답 생성 호출 없음. 대사와 타이밍은 제작자가 고정한다. 외부 TTS는 작성한 시연 문장만 전달하고 로컬 캐시에 저장한다.
- 추가 영상 생성 서비스 결제·가입 없음. 구성, 촬영, 편집, 그래픽은 로컬 프로젝트에서 재현 가능하게 만든다.

## 이야기

취향을 기억하는 내 친구 → 모바일 연결 → 차에서도 이어지는 여행 → 상대 캐릭터와 먼저 알아가기 → 두 경로 사이의 20분 약속 → 같은 표현으로 시작하는 실제 만남 → 서로의 선택을 존중하는 다음 여행.

중심 문장: `천천히 가도 괜찮죠.` 차량의 상대 캐릭터와 카페에서의 솔바람 대사에 같은 표현을 둔다.

## 화면 언어

깊은 청록 배경과 넓은 여백, 차분한 아이보리 타이포그래피. 앱은 원래의 밝은 오로라 배경을 유지한다. 주요 UI가 등장할 때 배경 경로가 하나로 이어지고, 카드가 모바일에서 차량으로 이동한다. 기기 회전은 가독성을 해치지 않는 작은 각도로 제한한다. 서사 피크에서는 움직임을 줄이고 목소리와 문장을 들려준다.

## QA 목록

- 모바일 캡처는 390×844 세로형이며 가로 찌그러짐 없음.
- 앱·제안·승인·모의 내비·독립 선택·양측 제출 후 결과의 순서가 명확함.
- 14:00~15:00은 공통 가능 시간, 14:15~14:35는 실제 약속, 14:35~14:55는 산책, 15:20 다음 일정으로 일관됨.
- 원본 캡처와 보완 그래픽 구분을 제작 기록에 보존.
- 한글 잘림·누락 글꼴·자막 겹침·비율 왜곡·장면 사이 공백 없음.
- 음성 시작/끝 잘림·대사 겹침 없음. 음악은 대사 아래에서 낮춰짐.
- 전 장면 대표 프레임과 전환 중간 프레임 확인. 최종 MP4 길이/해상도/오디오 검사.
